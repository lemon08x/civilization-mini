# 试玩约定

- 新批次按 `START_HERE.md` 执行。默认是当前模型亲自逐步决策，不是编写脚本基线。
- 每次行动必须基于最新观察；通过 `playtests/player.mjs observe / act` 操作。不得直接导入运行层、修改存档或用循环、条件策略、预排动作串代替模型决策。
- 可以用工具创建批次文档、记录笔记和整理已获得的观察与指标；这些辅助工作不得选择或自动提交游戏行动。
- 开局是准备操作，按入口文档使用 `lab new`；它不构成放开玩家操作权限。种子仅用于初始化，不用于选择行动。不得查看存档快照、随机状态、未来天气或结算源码来获得玩法优势。
- 默认自由探索，不先阅读历史攻略、试玩脚本和研究结论。用户指定路线或复核问题时，在任务说明中记录已知信息。
- 每批采用唯一编号，每局采用唯一 run ID；其他窗口的存档与笔记不覆盖、不接管。只有明确续玩时才继续已有批次。
- 逐局记录实际停止原因；达到试玩窗口不等于通关。不得把未开局、未完成或脚本代跑记为模型完成。
- 感受必须关联具体局号、revision 或季数，区分观察、推测和建议。一次观察不证明普遍规律，也不声称脚本具有主观体验。
- 不自动修改规则、构建工程、运行 `tests/`、重跑实验、调用付费 API 或创建常驻任务。缺少可用构建或存档身份不匹配时，保留现场并报告阻碍。
- 本目录是工作约定，不是工具权限沙箱；发现执行方式偏离时如实记录。
