## g01 / pt-20260914-162722-E40D-g01 / river / rev 0-86 / 绝对季1-25

- 开局：春1年，40岁，食物6钱8，12时间/8精力；已会A0基础栽培；天气干旱。
- 决策1（rev0）：春季播种小麦（3时间2精力），优先食物安全。
- 决策2（rev1）：学A1田间水分管理（干旱场景，为灌溉做准备）。
- 决策3（rev2）：建人工供水系统（2时间1精力）→ 调试（3时间2精力）→ 安排本人运行。此后干旱季系统自动灌溉小麦，观察确认"人工供水完成；实际扣费"，小麦免于缺水减产。
- 决策4（rev3-5）：秋收 wheat5；复种；卖大豆种子/亚麻种子/秸秆换现金。
- 关键观察：**储存容量只有4**，收获后小麦会"食品保存损耗"（wheat-1，protected 4）。买入基础容器S01（8钱）扩到8，解决损耗。
- 决策5（rev10-11）：秋收后学L0受力与运动基础；采木→建W01提水辘轳（3木+L0）。
- 决策6（rev14-15）：学M0材料识别→M1成形与连接；做工+卖小麦攒钱买2铁（7钱/份，订货下季交付）。
- 决策7（rev16）：冬末建T03锻打工具组（2木2铁+M1）——机械加工路径开启。
- 决策8（rev17-20）：学L1机械传动→L4水力动力；造传动轴（economy:process:shaft，2木1铁）→产品验证→卖1根轴得7钱→签稳定金属供货渠道（economy:channel:metal 3钱）。
- 后续：保持复种-收获循环，学O0劳动分工、O1生产工序、O2采购与交付、Q0基础数学；建单工位轴加工系统。
- 终局（rev86，绝对季25）：食物4（wheat 4）、钱4；设备W01+S01+T03（各耐久12/11）；知识11/25；era凭证155/12；家庭46岁/后辈22岁，健康100；无缺粮（hardship 0）。86次命令。
- 感受：前期容错靠食物缓冲；干旱季节灌溉设施是生命线；储存容量是隐性问题（收获多反而损耗）；机械加工是收入升级路径，传动轴7钱/根显著高于卖粮。

## g02 / pt-20260914-162722-E40D-g02 / clay-valley / rev 0-81 / 绝对季1-25

- 开局与g01相同，但我的节奏偏慢：秋收后没有立即复种，导致存粮见底。
- 关键观察：**绝对季15出现一次 hardship（缺粮）**：`consumed 0, missing 2, hardship 1`（秋收前存粮耗尽）；绝对季19再次缺粮 hardship 1。两次都靠"小麦成熟当季收获"才解除。对比g01全程未缺粮，差异来自我复种时机晚了一季。
- 场景差异：clay-valley 当地库存 wildFood 3、timber 5、clay 20（与river相同）。
- 经营路径与g01一致：W01→S01→T03→传动轴→卖轴→金属渠道；学A1/L0/M0/M1/L1/Q0。
- 终局（rev81，绝对季25）：食物5（wheat 5）、钱4；设备W01+S01+T03；知识7/25；era凭证143/12；hardship累计2次（metrics foodShortfall 4）；81次命令。
- 感受：**缺粮惩罚真实存在**（hardship），复种时机必须严格卡在收获当季或下季；同样路径下因为两季复种延迟就付出两次缺粮代价。这验证了"食物循环不能断"是这个系统的第一约束。
