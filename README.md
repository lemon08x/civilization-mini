# Civilization Mini · 世代规则预研

当前规则与工程 **0.27.0**（电气生产与现代通电验收）。新增燃料发电、储能、电灯、电报和电解制铝，手动供能仍需时间与精力。现代结算无实际用电服务时按85%兑现，最终副本需真实交付电力。详见 [v27实际规则与迁移](docs/CURRENT_GAMEPLAY_V27.md)。玩家随时结算进入下一社会，水井不是过关条件。各时代锁一部分科技，并提供不点科技树也存在的公共服务（公地采食、集镇公井、公共磨坊、市政自来水）。持续耕作仍可用。四个阶段各有192季时间预算。学习不消耗样品。

本版先落地农业供水与机械加工两条早期链，包含人工供水、机械供水、单工位轴加工三个系统。系统需建设、实际调试、安排人员；本人和员工共享各自的时间与精力预算，按实际任务结算工资、材料和设备耐用。流水线、阀控和无人化尚未开放。

四季一年，每季基础12时间；当季首次供电点灯增加2时间。后辈仍需按前置学习；直系前代学过的节点仅需1时间/1精力，家族产品记录和规程保留。基础农事与人工供水3时间/2精力；偶发缺粮有缓冲，饱食每季恢复5健康。采用新局，不迁移旧档，历史文件保留。旧泵免费灌溉和旧自动生产开关已替换；当前农业播种收获、采购和交付仍需本人操作，外部供粮/维修不算无人化。

详见 [0.26文明阶段](docs/CIVILIZATION_ERAS_V26.md)、[0.25自由点科技](docs/FREE_TECH_V25.md)、[0.24学科分叉](docs/BRANCH_MESH_V24.md)、[0.23建设结算](docs/SOCIAL_ERAS_V23.md)。旧版文档只描述各自版本。

## 开始试玩

需要 Node.js 24+。

```powershell
npm ci
npm start
```

打开 http://127.0.0.1:4317 选择入口：

- **人类玩家**：`/play`，通过聚落地点、资源卡、田地成长、家人状态与行动按钮推进。效果和前置条件可展开查看，无法执行的行动显示原因。
- **AI 文本玩家**：`/ai` 查看接入说明，或直接阅读 [AI_PLAYER.md](docs/AI_PLAYER.md)。`scripts/player.mjs` 默认精简观察；成功 `act` 返回最新摘要，不必再机械 observe。完整 JSON/text 仍可用。

两端共用规则结算，分别存档，不自动同步。入口与展示调整不改变规则或迁移历史存档。

新版使用独立浏览器存储键，保留旧档且不自动迁移。查看身体与家人面板和每个按钮的时间/精力报价，从农业页播种小麦、维持粮食开始，再建设工具与加工，按能力选择副本。在副本页查看真实生产要求、投入清单、运输和奖励；在家业页逐步委托经营。商城整单结账消耗时间与精力，订货通常次季到场；本季电报在线时新订货即时交付，仍扣资金、库存和运输。

打开 `/review` 查看规则总览、学科主干、产品效果目录和研究证据。产品的材料、学科、运行条件在具体详情中。历史实验不代表当前规则的新结果。

```powershell
npm run build
npm run lab -- new --run demo --seed 17 --scenario river
node scripts/player.mjs observe --run demo
node scripts/player.mjs act --run demo --revision 0 --action <从最新观察选择的行动ID>
npm test
```

玩家使用受限 `scripts/player.mjs`；网页、脚本和模型均通过同一行动接口。`src/game/game.ts` 是唯一结算权威，策略只读取 `observeSession()`。记录严格检查规则与实现指纹并重放；不能直接改存档优化参数。

## 研究边界

先记录假设，再用相同场景、种子与策略做小批量对照；候选写入 `experiments/`，不自动覆盖正式规则。不创建常驻优化循环、不默认调用付费API。当前验证使用脚本基线，不称为大模型AI。

雇佣、工资、材料与粮食都有实际成本。首副本可达不代表全路线已平衡。项目独立于 `../remake`，不引入 Cocos 或正式游戏工程。
