# Civilization Mini · 全年计划与生产力

当前规则版本 **0.27.0**。项目主线为：**设计一个人的全年计划，通过科技提高行为收益，在有限时间内形成高产、可持续运行的生产循环。** 当前只专注农业阶段。

本页“游戏主线”是已确定的产品方向；[现行玩法与实现状态](docs/CURRENT_GAMEPLAY_V27.md) 说明代码现在能做什么，[实施计划](docs/PR3_IMPLEMENTATION_PLAN.md) 记录尚待完成的工作。目录与分层见 [ARCHITECTURE.md](docs/ARCHITECTURE.md)，协作约定见 [AGENTS.md](AGENTS.md)。

本仓库只维护这一版规则。没有离线研究模块、脚本策略或旧版本规则 JSON。

## 游戏主线（2026-09-24 定案）

### 核心玩法：设计一个人的一年

玩家逐步定好每一天的行为，形成一份全年计划。个人年内可用时间有限，行为之间竞争时间，并受实际资源和生产条件约束。计划完整后自动运行一轮，以实际产出评价方案，再调整安排、提高成绩。

科技通过提高行为收益与效率，改善同一份全年计划的生产能力。成长目标是在当前阶段的科技和资源约束下，逐步达到稳定的生产力上限。无限扩张、无限积累和不断追加成长层级不再是主线要求。

核心循环：**逐步安排每日行为 → 自动执行全年计划 → 查看实际产值和瓶颈 → 调整计划、发展科技 → 提高稳定产值。**

自动执行应真实结算行为的劳动、材料、生活消耗和生产结果；“按计划自动执行”本身不意味着免除个人劳动成本。一次性耗尽存量得到的高产出，不能直接视为已经形成稳定循环；具体核算与持续性判定仍待设计。

### 胜利与评分：四阶段计划产值

整体成绩按四个阶段的计划产值及其占比计算，越后期的阶段占比越高。四阶段沿用农耕村落、市镇百工、电力工业、现代社会的结构；各阶段都围绕全年计划贡献成绩。

- 玩家可以只专注一个阶段，反复优化该阶段的计划、追求高分。
- 玩家也可以追求整体得分，平衡各阶段收益和投入。
- 总分关系为各阶段计划产值按权重汇总；后期权重大于前期。具体比例、产值单位、跨阶段折算与缺席阶段的计分方式尚未确定。
- 现代危机副本不再是设计上的胜利目标或唯一计分来源。门派背景与传承关系保留，承担跨时代个人发展的叙事基础；核心玩法与成绩围绕全年计划。修行、气运和传承的具体机制如何服务新玩法，另行设计。

### 剧情背景：门派中的生活与学艺

**门派背景保留。** 门派为个人在农耕村落、市镇百工、电力工业、现代社会四个时代中的持续发展提供身份、关系与学问延续的基础。更换生产与评分主线，不等于取消门派世界观、师徒关系或原有的山居生活质感。

沿用虚构门派取意于墨家兼爱、非攻与鬼谷隐世求学的来处，将后续叙事重心放在生活、学艺、同门往来和对新事物的好奇上。全年计划是门人在田间与日常生活中安排所学、逐步改善生活的方法；科技进步应让玩家看见自己的办法越来越好，时间与收成的安排越来越从容。

游戏整体追求轻松、亲切、有趣的质感。门派设定让玩家与现实中的生计和绩效压力保持距离；故事与美术通过人物交往、生活细节、季节变化和时代中新器物的出现增加趣味。真实的生产约束仍由游戏规则承担，不把低分叙述为失职、辜负师门或道德失败。

四时代的环境、工具与所学可以变化，门派带来的归属感与个人成长应保持连续。后续剧情不再围绕“历代积蓄只为现代灭绝危机兜底”展开；现代阶段也应延续生活与学艺的基调。旧使命代码的调整仍属于后续机制工作。

跨时代通过**师徒接续**延续玩家的经历，不采用同一人物长生跨越四时代的解释。门派保存传承，弟子接过前人的生活与事业，个人能力仍需实际培养。现有交接机制继续作为衔接基础，具体调整不因背景定案自动完成。

修行的核心已经确定为：**为人物的全局行动提供加成，同时持续占用时间维护，升级则需要更多时间投入。** 当前已落地16门修行课程，借用《老子》《庄子》《墨子》《鬼谷子》等古典思想，从修身分出养身、养心、明理、处世四支，再会通所学。日课、分段精修和师徒传习真实占用时间；课程效果按要求留空，尚不提供全局数值加成。结构与后续工作见 [实施计划](docs/PR3_IMPLEMENTATION_PLAN.md)。

### 当前开发范围：农业

当前仅推进农业阶段的全年计划体验，不同步扩展市镇、工业或现代玩法。后续阶段保留评分结构与方向，具体行为另行设计。

种地与需要时间维护、升级的修行是已经确定的计划方向。现有课程学习与日课仍需手动执行，全年计划自动调度尚未接通；修行效果及其他辅助行为仍待设计。

休息与口粮、时令采集、堆肥与农产处理、学习与生产建设是可评估的候选行为，不是已经批准的全部功能清单。选择行为时应说明它占用什么时间、影响什么收益、如何与种地形成取舍；不为填满日历添加没有决策价值的操作。

### 尚待设计的规则

- 全年计划的起止日期、跨年作物处理、每日行动粒度与一次性行为的重复规则。
- 计划如何逐步形成、修改和试跑，建设与学习是否进入被评分的年度；发展期限与四阶段之间的投入关系。
- 天气变化、缺料、劳动冲突等情况下的执行规则，是否允许条件安排和备用行为。
- 产值口径、外部采购与期初库存的扣算、中间产品重复计分、设备与资源消耗、循环稳定性判定。
- 四阶段具体权重、阶段成绩的可比方式、单阶段成绩的呈现与综合成绩结算。不默认新增联网排行榜。

以上未定项不得因本文自动选定数值或机制。本文替换原“修道习术—师徒传承—现代使命”的玩法与评分主线及“无限发展”要求，保留门派背景和跨时代个人发展的叙事基础；不将讨论中的建议直接视为已定规则。

## 当前实现状态

农时已有年度计划、劳动报价、冲突与缺料提示，但农活仍逐项手动执行；通用全年计划自动执行、稳定循环评估和四阶段计划产值评分尚未实现。修行课程树、日课、精修与传习已接入，旧五境和机缘加成停用。现有师徒交接及旧现代使命结算仍运行，部分开场背景文案尚待同步，不代表继续沿用旧目标。

课程重构更新了修习状态；旧五境存档不迁移、不覆盖，需新开游戏。规则版本仍为0.27.0。

## 开始试玩

朋友试玩可从 [Releases](https://github.com/lemon08x/civilization-mini/releases) 下载 `CivilizationMini-v0.27.0-windows-x64.zip`，完整解压后双击 **启动游戏.cmd**。便携包自带运行环境，无需安装 Node.js、npm 或联网安装依赖；请保留启动窗口，关闭它即停止服务。浏览器中从“农场 → 土地指南”了解土地玩法。

存档保存在当前浏览器的本机数据中。请使用同一浏览器和地址（默认 `http://127.0.0.1:4321`），不要清理网站数据；换电脑或升级前，在游戏“选项”中导出存档。旧结构存档不迁移，导入不兼容时保留原文件并新开旅程。便携包面向 Windows 10/11 x64。

从源码运行需要 Node.js 24+。

```powershell
npm ci
npm start
```

打开 http://127.0.0.1:4317 ：

- **人类玩家**：`/play`
- **AI 文本玩家**：`/ai` 或 [AI_PLAYER.md](docs/AI_PLAYER.md)。`playtests/player.mjs` 默认精简观察。

```powershell
npm run build
npm run lab -- new --run demo --seed 17 --framework riverine
node playtests/player.mjs observe --run demo
node playtests/player.mjs act --run demo --revision 0 --action <可用行动ID>
```

`src/game/game.ts` 是唯一结算权威。网页从开始界面打开存档或新开；命令行存档在 `saves/`（不入库）。
