# Civilization Mini · 世代规则预研

当前规则与工程 **0.21.0**（社会食品与生活安排）。在「生活与食品」选择自给补缺、市场生活或保留储备；零家庭存粮也可依靠有资金、有货源的真实采购维生。学科只依赖前置知识，学习不再消耗样品；产品检查前置产品验证与学科，区分实物、验证记录和制造规程。

本版先落地农业供水与机械加工两条早期链，包含人工供水、机械供水、单工位轴加工三个系统。系统需建设、实际调试、安排人员；本人和员工共享各自的时间与精力预算，按实际任务结算工资、材料和设备耐用。流水线、阀控和无人化尚未开放。

四季一年，每季12时间。后辈仍需按前置学习；直系前代学过的节点仅需1时间/1精力，家族产品记录和规程保留。基础农事与人工供水3时间/2精力；偶发缺粮有缓冲，饱食每季恢复5健康。采用新局，不迁移旧档，历史文件保留。旧泵免费灌溉和旧自动生产开关已替换；当前农业播种收获、采购和交付仍需本人操作，外部供粮/维修不算无人化。

详见 [0.21社会食品](docs/SOCIAL_FOOD_V21.md)、[0.20规则与验证](docs/RECOVERY_V20.md)、[0.19规则与范围](docs/THREE_TREES_V19.md)、[实施验证](experiments/industry-v19-report.md)和[三类树预研](experiments/three-trees-preresearch.md)。旧版文档只描述各自版本。

## 开始试玩

需要 Node.js 24+。

```powershell
npm ci
npm start
```

打开 http://127.0.0.1:4317 选择入口：

- **人类玩家**：`/play`，通过聚落地点、资源卡、田地成长、家人状态与行动按钮推进。效果和前置条件可展开查看，无法执行的行动显示原因。
- **AI 文本玩家**：`/ai` 查看接入说明，或直接阅读 [AI_PLAYER.md](docs/AI_PLAYER.md)。建档和行动后生成 `artifacts/runs/<run ID>/observation.md`；模型读取文件，再通过 `scripts/player.mjs act` 提交行动。支持 `--format text`，默认 JSON 接口保留。

两端共用规则结算，分别存档，不自动同步。入口与展示调整不改变规则或迁移历史存档。

新版使用独立浏览器存储键，保留旧档且不自动迁移。查看身体与家人面板和每个按钮的时间/精力报价，从农业页播种小麦、维持粮食开始，再建设工具与加工，按能力选择副本。在副本页查看真实生产要求、投入清单、运输和奖励；在家业页逐步委托经营。商城整单结账消耗时间与精力，订货次季到场。

打开 `/review` 查看规则总览、学科主干、产品效果目录和研究证据。产品的材料、学科、运行条件在具体详情中。历史实验不代表当前规则的新结果。

```powershell
npm run build
npm run lab -- new --run demo --seed 17 --scenario river
node scripts/player.mjs observe --run demo
node scripts/player.mjs act --run demo --revision 0 --action <从最新观察选择的行动ID>
npm test
```

玩家使用受限 `scripts/player.mjs`；网页、脚本和模型均通过同一行动接口。`src/game/game.ts` 是唯一结算权威，策略只读取 `observeSession()`。记录严格检查规则与实现指纹并重放；不能直接改存档优化参数。

## 研究边界

先记录假设，再用相同场景、种子与策略做小批量对照；候选写入 `experiments/`，不自动覆盖正式规则。不创建常驻优化循环、不默认调用付费API。当前验证使用脚本基线，不称为大模型AI。

雇佣、工资、材料与粮食都有实际成本。首副本可达不代表全路线已平衡。项目独立于 `../remake`，不引入 Cocos 或正式游戏工程。
