## 背景、中心主题与开发方向

本节记录创作方向；师徒、修道、衍生机缘与现代使命已接入现行玩法。游戏内可在开始界面的「门派缘起与传承之志」阅读背景，在游戏选项中可随时打开。

### 门派缘起与师徒传承

本作借用墨家兼爱、非攻与鬼谷一脉隐世、韬光养晦的思想构造虚构流派。墨家济世的失败使传人转而隐世积累，保存学问并紧跟时代前沿。玩家所在流派以师徒传承延续到现代：**每代两位传人，每人各收一名徒弟，组成下一代。** 不同代次可以同时在世，并非全流派同时只能有两个人。

门人可以结婚生子，也可以不婚育，私人生活与门派继承无关。配偶、子女不自动入门，不能凭血缘取得传人席位。这一设定替代旧版的家庭血缘主线与“每代唯一命定之人”。

门派只为人类存续兜底：人类处于灭绝边缘时才整体出手，局部灾荒不自动触发使命。平日观察、思考、修行与积累，提升能力是主线；偏离主线不获奖励，兼顾成长与善行则有额外奖励。允许一时自私，但须恪守无私信念。

### 中心主题：道以传志，术以济世

**人类掌握力量的速度，超过了学会驾驭力量的速度。师徒代代修道习术，让一门学问持续生长，在人类可能毁灭自身时承担最后的责任。**

- **道**：心法、冥想等内在修炼，影响做其他事情的效果，是门派最重要的传承。每人入门都须从头修习，不能直接继承师父的个人修为。
- **道的改进**：门人可以艰难地改进本门修炼方法，成功后形成门派永久提升。传下的是更好的道法，后人仍须亲自修炼。
- **术**：现有科技树、知识、生产与实践能力。道改善学术用术的效果，但不代替知识前置、材料、设备与实际学习。
- **潜龙勿用—见龙在田—飞龙在天**：平日隐世积累，有限实践；进入现代、面对必须解决的副本后，全面施展历代所学。

### 修道机缘与现代使命

气运是“道”的次要衍生效果：修行带来少量机缘储备，并对随机机遇产生小幅影响，不设独立气运养成路线。抽卡仍消耗气运，但只是可选辅助；不抽卡也能修道习术、收徒并完成兜底任务。消耗气运不会降低个人修为或门派永久道法。

门派最重要的积累仍是道法的改进。招徒资质机会只受修道衍生效果轻微影响，不因拜师重写已有天赋，也不依赖气运抽卡获得合格传人。信物承担门派联系；概率偏置是世界观中的虚构解释，不是与道并列的另一套力量来源。

现代人类认知与自我约束尚未跟上，却已有足以毁灭自身的力量。AI 与生物技术滥用、核升级与战争、生态和气候危机构成副本背景。当风险达到人类存续底线，门派召集传人承担必须解决的任务。

**副本是最终分数唯一来源，同一副本有不同难度和奖励分。** 道、术与实际物资构成应对任务的主要能力，不直接折算最终得分。当代第二名传人的存在与收徒属于本轮必做规则；远征同行的协作玩法仍保留为后续方向。

### 实施计划与当前边界

[PR3 实施计划](docs/PR3_IMPLEMENTATION_PLAN.md) 随第一笔提交建立，并按最新设定持续修订。计划明确区分用户确定要求与实施默认方案，按以下顺序落实：

- [x] 两人一代、各收一徒、私人婚育与师徒继承分离。
- [x] 个人从零修道、道影响其他行动、困难改道带来门派永久提升。
- [x] 以修道为主的成长奖励、少量衍生机缘与可选抽卡辅助。
- [x] 现代召集、危机副本、难度与最终评分。
- [x] 桌面界面、AI 观察和现行玩法说明同步。

当前已实现上述机制，私人婚育与远征同行未加入模拟。实际公式与边界见现行玩法说明。旧存档不迁移、不覆盖，需新开游戏；规则保持0.27.0。完整长程与多路线平衡尚待专项验收，PR继续保留草稿。

## 开始试玩

需要 Node.js 24+。

```powershell
npm ci
npm start
```

打开 http://127.0.0.1:4317 ：

- **人类玩家**：`/play`
- **AI 文本玩家**：`/ai` 或 [AI_PLAYER.md](docs/AI_PLAYER.md)。`playtests/player.mjs` 默认精简观察。

```powershell
npm run build
npm run lab -- new --run demo --seed 17 --scenario river
node playtests/player.mjs observe --run demo
node playtests/player.mjs act --run demo --revision 0 --action <可用行动ID>
```

`src/game/game.ts` 是唯一结算权威。网页从开始界面打开存档或新开；命令行存档在 `saves/`（不入库）。
