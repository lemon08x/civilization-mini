## 背景、中心主题与开发方向

本节记录已确定的创作方向，作为后续机制、玩法与数值设计的依据；不表示相关系统已经实装。游戏内可在开始界面的「门派缘起与传承之志」阅读背景，在游戏选项中可随时打开。

### 门派缘起与玩家身份

本作是借用历史思想的虚构设定。墨家济世的失败，促使一支传人以兼爱、非攻为中心信念，吸收鬼谷一脉隐世、韬光养晦的处世思想。掌门决定化整为零，令门人散居世界各处，以家为单位独立发展。玩家经营其中一个分支，深耕家庭，修身养性，学习并掌握时代前沿的知识与能力，将传承延续到现代。

门派只为人类存续兜底：只有人类处于灭绝边缘时才整体出手。局部灾荒即使造成大量死亡，只要未危及人类存续，也不触发使命；门派仍以观察、思考和积累为常。日常主线是提升自身能力，偏离主线的事不会获得奖励；若能兼顾善行与能力提升，则获得额外奖励。允许一时的自私，但必须恪守无私的信念，不能忘记最终的兜底责任。

### 中心主题

**人类掌握力量的速度，超过了学会驾驭力量的速度。以家庭为根基积累世代之力，在人类可能毁灭自身时承担最后的责任。**

- **潜龙勿用**：平日隐世经营，发展能力，保存和延续传承。
- **见龙在田**：有限施展、验证所学；现代副本开启之前，至多止于这一层。
- **飞龙在天**：进入现代，面对必须解决的副本任务，才全面施展积累的能力。

这些是叙事与玩法方向，尚不是现行规则中的阶段字段或能力锁。

### 信物、命定之人与气运

家族信物给予家族特殊能力：每代都有且仅有一位命定之人，他的决定影响家庭气运，气运影响好运事件与下一代天赋的概率。代价是拥有这份力量的人永远无法摆脱门派联系，可以被门主找到。

现代的世界观解释是「对可能结果的概率分布施加偏置」。它借用量子概率的意象，是本作新增的虚构物理规律，不是现实波粒二象性已经证明的宏观好运机制。

奖励可由抽卡承接；抽卡消耗气运，气运同时影响抽取概率。气运如何获得、按消耗前还是消耗后计算概率、是否影响同一时点的后代天赋、卡池内容与概率边界，尚待机制设计，不在本次背景更新中确定数值。后续需检查抽卡所得是否能形成气运自我增殖，以及低气运时是否仍有成长空间。

### 现代危机与最终目标

人类认知和自我约束的发展滞后，却已经拥有足以自我毁灭的「上帝之力」。副本背景可以包括不受约束的 AI 发展与生物技术滥用、将「黑暗森林」视作行动准则而升级的核威胁、一触即发的世界大战，以及无视环境代价造成的生态和气候危机。厄尔尼诺等自然波动可与变暖、极端天气叠加；不将其简单写成污染直接导致的频次增加。

当这些风险发展到人类灭绝的边缘，门派通过信物召集门人，开启必须承担的现代副本任务。召集目前只承担副本开启的背景功能；同门同行保留为后续扩展方向。

**副本是最终分数的唯一来源，游戏最终比较得分高低。** 同一副本设置不同难度，给予不同等级的奖励分；家庭财富、知识、生产与天赋用于形成应对能力，不直接折算为最终分数。副本难度、失败与重试、重复计分、一局时间边界均未定案。

### 后续设计的取舍依据与当前边界

- 机制与玩法围绕「发展家庭能力 → 跨代积累 → 在现代副本中施展 → 获得分数」展开；新内容应说明服务于哪一环。
- 数值奖励能力提升，兼顾善行可获得额外奖励；气运同时承担抽取成本与概率影响，需一并评估消耗和成长收益。
- 现代副本承担最终目标，难度与奖励分体现能力的价值；具体危机不能只换背景文字而与家庭积累无关。
- 当前 0.27.0 已有经营、学习、传承和现代副本任务计分。信物、命定之人、气运抽卡、上述危机副本的难度分级和同门同行尚未实装。
- 当前跨时代会生成无亲属关系的新人物与家族，后辈天赋仍按现有出生随机规则产生。与长期家族设定的衔接，留待后续机制任务处理；本次仅更新背景呈现，不改结算、存档、数值或规则版本。

## 开始试玩

需要 Node.js 24+。

```powershell
npm ci
npm start
```

打开 http://127.0.0.1:4317 ：

- **人类玩家**：`/play`
- **AI 文本玩家**：`/ai` 或 [AI_PLAYER.md](docs/AI_PLAYER.md)。`playtests/player.mjs` 默认精简观察。

```powershell
npm run build
npm run lab -- new --run demo --seed 17 --scenario river
node playtests/player.mjs observe --run demo
node playtests/player.mjs act --run demo --revision 0 --action <可用行动ID>
```

`src/game/game.ts` 是唯一结算权威。网页从开始界面打开存档或新开；命令行存档在 `saves/`（不入库）。
