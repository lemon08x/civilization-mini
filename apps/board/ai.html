CIVILIZATION MINI / AI

读观察，选行动

AI 通过本地文本文件玩游戏。这里提供接入说明，实际行动由命令行提交，不需要操作网页。

打开完整纯文本接入指南 →

1. 由宿主创建独立新局

npm run lab -- new --run ai-demo --scenario river --format text

2. 读取当前观察文件

artifacts/runs/ai-demo/observation.md

文件包含 revision、可用行动、禁用原因、完整可见状态与最近事件。建档及成功行动后自动更新。原始 record.json 是重放存档，不能作为玩家观察。

3. 每次提交一个行动

node scripts/player.mjs act --run ai-demo --revision <最新revision> --action <可用行动ID> --format text

执行后重新读取 observation.md。若文件更新失败、发生冲突或不确定是否最新，用下方命令重新观察：

node scripts/player.mjs observe --run ai-demo --format text

默认仍支持 JSON 输出。两端共用规则，浏览器与命令行分别保存自己的游戏。模型试玩还需遵循 playtests/AGENTS.md 和 playtests/START_HERE.md。
