# 0.26.0 文明阶段：自选结算、锁科技、社会服务

社会是文明背景，不再用建成水井或泵来结束一个时代。玩家随时可以结算；每个时代锁一部分科技，同时提供不点科技树也存在的公共服务。

## 何时离开这一段

- 行动 `economy:erasettle:stage`：结束本季，按当前产能推算剩余时间，兑现本阶段回报，进入下一社会。
- 时间预算用尽（默认 192 季）仍会结算，但只兑实际生产。
- 水井、泵、轴工位是可选的家庭建设，不是过关条件。
- 现代家业试炼只影响胜负，不是离开现代的条件。

## 科技开放

已学会的知识跨阶段仍生效。学堂里未到社会阶段的课显示“当前社会尚未开放”。观察 `game.era.lockedKnowledge` 列出尚未开放的课程。

| 社会 | 新开放（相对前一段） |
|---|---|
| 农业村落 | 栽培/水分/肥力/油料、材料识别与储存、基础力学、劳动分工、基础数学、井渠 |
| 集镇分工 | 成形与密封、传动/流体/泵、工序与交付、应用数学与账目、集镇核算 |
| 工业城镇 | 水力与发电、电工绝缘与绕组、工厂批次管理 |
| 现代社会 | 配电、当代调度 |

## 不靠科技树的社会服务

| 社会 | 服务与机制 |
|---|---|
| 农业 | 公地采食 +1；村社帮工收入 +1；收获凭证权重大 |
| 集镇 | **公井**：旱季为家庭田补水，不必先学泵 |
| 工业 | 稳定铁料与电工材料市场；**公共磨坊**（2 小麦→1 面粉，1 钱，每季一次，无需磨粮知识）；加工凭证权重大 |
| 现代 | 口粮配送；可付费自来水；最终副本；公井改为市政自来水 |
