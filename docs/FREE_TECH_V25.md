# 0.25.0 自由点科技与持续耕作

学科树已经分叉，不再按时代锁课。田间可以安排一次持续耕作，季末自动收获并复种。

## 自由点科技

A2 井渠、O3 集镇核算、O4 工厂批次、O5 当代调度去掉阶段限制。前置满足即可在任何社会学习。已建水井仍跨阶段保留。

O3 / O4 / O5 任一门使当期生产凭证 +25%，三门不叠乘。时代建设目标（井 / 泵 / 轴工位 / 家业试炼）和剩余产能推算不变。

## 持续耕作

`economy:farmcycle:<作物|off>`。安排后季末：成熟则收获，空田则按同一作物补种。缺种子停在空田。劳动按一次播种或收获扣本人时间精力，或扣农工工资。生长中且无需收获/补种的季不扣。仍可手动耕作；供水系统继续负责缺水季。

不重开自动补货、自动销售。轴加工系统安排人员后本来就会跨季运行。
