# 0.20.0 恢复、农业起步与代际学习

已获用户实施授权；假设见 experiments/recovery-v20-hypotheses.md。三类树依赖类型保持原设计。

## 生存与农业

- 每季12时间；基础播种、照料、收获以及人工供水3时间/2精力。健壮天赋仍降低个人体力劳动1精力；系统使用统一任务报价。机械供水2时间/1精力，继续提供效率升级。
- 粮食缺口除以本季需求得到缺粮比例。连续缺粮第一季不伤健康；第二季按半强度、第三季起全强度乘缺粮比例扣健康，伤害向上取整。基础伤害仍15。供粮恢复后连续计数归零。
- 缺粮季仍恢复至少1精力；半饥饿恢复更多。饱食恢复正常3精力，不再随低健康二次降低；善恢复额外加1。
- 饱食每季恢复5健康，不超过年龄上限；最低精力容量4，主动休息仍花4时间恢复5精力。长期断粮仍可能死亡，不提供永久免疫或无限资源。
- 疗养2时间/1精力/1钱恢复8健康，不代替口粮，不逆转衰老。

## 代际学习

直系祖先个人记录中已经学过的节点，后代仍需检查前置并执行学习，每节点最多1时间/1精力。初代首次探索通常4/2，天赋和家学照常影响首次成本。记录覆盖所有保留的直系祖先，死亡或退休不失效；不是全家最高等级，不借用子孙知识给长辈减费，不跨无关分支，不因购买设备自动掌握。

教导让后辈在接班前学会一个节点，免去其接班后的那一次学习；不教导也能以低成本自行学习。手动家学记录仍有首次探索减时作用，但不是祖先减费的必要按钮。

产品验证、制造规程和系统仍跨代保留；本人操作系统接班后需重新安排。交接与代末事件的mastered改用真实分支节点，避免旧字段显示空列表。

## 可规划预算

观察提供总时间、已用、剩余、系统预留、自由可用时间与精力及逐任务明细；网页头部显示扣除预留后的时间。播种、照料和收获在隔离副本上使用同一个农事结算计算行动后需求，不改真实状态、不另写一套农事规则；行动后预留纳入可用性检查。安排、暂停、拆除也预览预留。

人员分配要求具备潜在任务容量，与本季实际需求分开解释。无需求不实际预留；暂停/改派释放预留。报错给出剩余、行动耗费、预留明细。健康显示当前年龄上限。

## 验证与结论范围

10项专项测试覆盖配置隔离、饥饿递进、恢复与衰老、季末缺粮计数、祖先方向、逐节点重学与交接事件、播种新预留、浇水释放预留、疗养及新档严格重放。

小批量脚本基线（不是大模型试玩）：river场景、种子17/29、同一只读观察决策策略，各运行12季。旧版学习节点16/17，新版19/18；四个运行均无缺粮，健康100。说明此策略开局探索余量增加，但不能证明受挫恢复、系统长期经营或整局难度已平衡；恢复机制由专项边界测试验证。早期学完19节点也提示后续应观察“学科探索与产品实践的节奏”，不据此宣称全局平衡完成。
