# 产品树与研究入口

主导航：规则总览、科技树、产品树。参数与权限、实验与提案、跨领域规划收进“研究工具 · 实验与调参”，保留调参白名单及历史证据的核对能力，不作为玩家教程主线。

产品树入口 `/review#products`。按食品与储存、药品与医疗、材料与金属、工具与设备、知识成果分组。主图仅包含产品节点；点击查看来源、配方条件、用途与后续产品，可从已有生产方法跳到对应科技。

当前22个现行节点来自现有产品、资源与设施；工业和设备生产关系从现行关系投影提取。21个规划节点包含谷物加工、药剂、铜铁冶炼与工具，以及算术方法、几何测量记录、力学模型、热学记录和工程图。规划以虚线与明确文字区分，可整体隐藏。规划节点间连线仅为设计假设，没有新增可玩配方、数值或物理效果。

知识学科不直接成为库存；知识产品应是能够形成、使用、保存或传授的具体成果。数学物理节点需要之后明确的机制提案与验证。医疗尤其需要先定义健康、疾病、治疗和成本；铜铁生产需要矿产、炉具、燃料和工序。

版本与迁移：本次为展示与独立规划，不改规则0.6.0，不更换存档键，不迁移历史存档，也不运行新平衡实验。保留全部历史提案和报告。

验证：64项测试通过，包含现行/规划边界、图引用有效性与产品到科技入口；网页验证了分类筛选、隐藏规划、节点选择与研究工具入口。

## 分层阅读更新

默认展示现行产品的领域总览，不绘制产品级连线。进入领域后只画分支主线，通用木材、黏土、口粮投入和设备支持保留在详情。跨领域关系显示为可点击入口，进入目标所属分支，不铺跨区长线。支持一层上下游、返回上一层（含分支、内容模式与画布滚动位置）、独立陶料回收循环和产品搜索定位。

现行与规划采用互斥模式；分类内节点位置固定，选择节点不会重新布局。无现行产品的领域显示空态。科技树继续展示现行17项科技，默认必要前置，选中节点才显示其有利经验，任选前置在条件组中查看；提供搜索定位。

本次仍为只读说明界面，不显示虚构的个人掌握状态，也不改变规则或存档。65项测试通过，已短时检查分类、局部追踪、循环与返回、现行/规划切换。原报告不更新指纹。
