# 全年计划与生产力主线实施计划

更新：2026-09-24。沿用本文件路径，替换原 PR3 的师徒传承、道术修行与现代使命实施计划。当前产品方向以 [README 游戏主线](../README.md) 和 [AGENTS.md](../AGENTS.md) 为准；旧主线不再作为后续开发要求。

## 玩家问题与已确定目标

现在的农时安排能表达播种、施肥与收获日期，但仍需逐项手动执行，最终成绩也仍来自现代危机，无法评价玩家设计的全年生产方案。

已确定的新目标：玩家逐步安排一个人每一天的行为，构成全年计划；科技提高行为收益与效率，最终在有限时间和资源条件下达到稳定的生产力上限。完成的计划自动运行一轮，以实际计划产值评价。四阶段按占比贡献整体成绩，后期占比更高；支持只优化一个阶段，也支持平衡各阶段以追求整体得分。当前只开发农业，已确定种地及需要时间维护、升级的修行方向，其他辅助行为仍待设计。

背景补充：门派保留，通过师徒接续延续玩家跨四时代的经历，并通过生活、学艺、同门关系与美术表现维持轻松有趣的质感。重构的是旧危机使命对剧情的牵引，不是取消门派。修行为人物全局行动提供加成，维护占用时间，升级需要更多时间；课程树、日课、精修和传习已接入代码，课程效果按要求留空。开场与游戏内背景文案需随后同步。

## 修行课程重构（已实现基础，效果留空）

旧五境直线升级已替换为16门前置课程：修身入门，分养身、养心、明理、处世四支，汇入知常、成己成物与道法自然。名称、出处、习练内容及前置关系见 [现行玩法](CURRENT_GAMEPLAY_V27.md) 与 `src/game/model/life.ts`。

已实现：个人独立进度、全部前课检查、分段精修、随日历消耗的功课储备、耗时日课、师徒双方占时传习、交接保留本人学习状态、桌面课程树及AI观察。精修和日课在实际时间经过后记入成果。旧境界、心法、卡牌及随机启发的数值加成与入口已停用；旧结构字段暂保留，不能据其推断仍有收益。

课程效果统一为 `null`。当前真实扣除学习与维护时间，但不给生产、学习、恢复或评分加成；界面显式说明效果待定。日课与精修的现行成本、功课储备及课程层次只是可运行的学习节奏，后续效果与平衡另行设计，不套回旧倍率。

后续需要完成的效果设计：

- 将实际课程成果与功课状态接到人物全局行动，明确收益适用范围、叠加方式和上限。
- 让有效劳动进度累计，解决半天取整吞掉小幅收益的问题；不能只改报价显示。
- 长行动按实际时间段应用维护状态，避免开工时锁定满额加成直到完工。
- 日课与精修自身不自我加速，同一动作不同时加速和倍增产物；自然成熟、原料与最终分数不直接乘修行倍率。
- 以有限课程与实际维护时间形成稳定年度循环，再决定门派长期心法的进一步作用；不恢复无限刷修为或随机抽卡作为成长主线。

现有 `model/life.ts`、`systems/life.ts`、`actions/life.ts` 承担课程目录、进度和行动，`systems/time.ts` 结算维护衰减。世界变化仍经 `game.ts` 的 `transition`；`sectView`、修炼页和AI观察展示一致状态。存档形状已更新，规则仍为0.27.0，旧五境存档拒载且不覆盖。

## 农业实施顺序

以下为实施拆分，尚未开始的项目不标记为完成。每项按当次任务推进，不因本计划自动新增子系统或扩展后续时代。

1. **确定计划与产值口径。** 明确年度边界、每日行为粒度、计划形成与修改方式、评分年度与发展时间的关系；确定农业产值如何对待原料投入、存量消耗与跨年收获。
2. **接通种植计划执行。** 复用现有农时、地块和行动，实际扣除个人时间与资源；明确任务排序、冲突、缺料、异常和终止条件。观察必须说明计划做了什么、为什么未能执行。
3. **确定农业辅助行为。** 评估休息与口粮、时令采集、堆肥与处理、学习和建设；逐项选择能形成时间与收益取舍的行为。候选内容不等于全部必须实现，也不默认扩展畜牧等新系统。
4. **评价完整年度。** 展示实际产值、主要瓶颈及影响继续运行的资源变化，让玩家能够依据结算调整计划。稳定循环的判定方式应先确定，再实现。
5. **接入科技优化。** 说明科技怎样提高行为收益、节省劳动或缓解时间冲突；具体数值另行设计，不同时进行无关调参。
6. **衔接整体评分。** 农业方案成立后，再落实阶段成绩保存和四阶段加权结构。后续三阶段的具体生产行为与玩法暂不展开。

## 实现约束

- 先改现行 model、systems、actions、observation，再同步桌面界面与 AI 观察；世界变化只通过 `src/game/game.ts` 的 `transition`。
- 自动执行不免除行为成本，不用前端假状态或外部策略脚本替代游戏机制；不能读取未来天气或随机状态。
- 农业已经按日历运行，部分工业与经营仍使用90天兼容周期。后续扩展时单独处理，不为当前农业任务顺带重写所有行业。
- 新主线不要求无限扩张，也不要求延续“修行为主、现代副本唯一计分”的旧设计。门派背景与传承关系已经确定保留；师徒、修行、气运的具体机制如何服务全年计划，以及旧使命如何替换，应在相关任务中明确，不能把背景保留等同于旧评分继续有效，也不能把文档变更当作代码已经移除。
- 当前仍为0.27.0，不迁移旧档，不自动改规则版本或 bounds。新增内容、测试和界面核验遵循根 AGENTS.md；未明确要求时不运行测试。
