# PR3 实施计划：师徒传承、道术修行与现代使命

## 1. 目标与使用方法

玩家目前可以经营、学习和交接，但门派背景尚不影响选择；跨时代会换成无亲属关系的新家族，现代终局仍是余粮、传动轴和通电等任务的单一清单。本 PR 要把已确定的主题落实为完整循环：**修道习术 → 师徒传承与道的永久改进 → 现代承担危机任务 → 按副本难度与成果计分**。

本计划随 PR3 第一笔提交交付。基线为 PR2 合并后的 `main`（`fb72f0a`），规则 0.27.0。实施前核对实际代码，按阶段推进并更新清单；不能以增加背景文案或展示不可操作的界面代替机制完成。

第 2 节是用户已经确定的要求；其余章节的具体公式、卡池、难度与节奏是本计划提出的**实施默认方案**，不是用户此前逐项确认过的规则。实施者可以根据现行模块作局部调整，须同步本计划说明原因，不能改变第 2 节。数值越界、规则升版等仍按根 `AGENTS.md` 处理。首笔提交只含计划；当前实施口径见第12节。

## 2. 已确定的创作与玩法要求

- 虚构流派奉行墨家兼爱、非攻，因墨家失败而吸收鬼谷一脉隐世、韬光养晦的处世思想。门人隐世修行，紧跟时代前沿；玩家所在流派以师徒关系传承，每代两位传人，每人各收一名徒弟组成下一代。
- 门派只在人类处于灭绝边缘时出手兜底；局部灾荒即使造成大量死亡，也不自动触发门派任务。平日观察、思考、修身与积累。
- 提升自身能力是主线。偏离主线的事不获得奖励；兼顾善行与能力成长时有额外奖励。允许一时自私，但恪守无私信念。
- 平日「潜龙勿用」，有限施展至多「见龙在田」；进入现代、开启必须解决的副本后才「飞龙在天」。
- 师徒传承取代血缘继承和“每代唯一命定之人”。门人可婚育也可不婚育，配偶与子女不自动入门，不影响门派继承资格。信物联系保留，气运降为道的次要衍生效果，不设独立成长路线；原先气运与后代天赋的关系如何转接到招徒，按第 5 节的实施默认方案处理。
- “道”是心法、冥想等内在修炼，影响做其他所有事情的效果；现行科技树归为“术”。每人入门从头学道，前人的个人修为不能直接继承；改进本门派的道很难，但成功后形成跨代永久提升。
- 气运在现代以概率分布偏置解释。这是借量子概率意象构造的虚构规律，不将宏观好运描述为现实波粒二象性的已知结论。
- 道的确定性成长与永久改进是核心，气运只为机遇带来小幅偏置；抽卡仍消耗气运并受其影响，但属于可选辅助，不是修道、收徒或完成副本的必经途径。
- 人类认知与约束力量的能力落后于其破坏能力。现代危机涉及 AI 与生物技术滥用、核升级与世界大战、环境与气候系统性风险。
- 现代副本是必须承担的事，也是最终分数唯一来源。同一副本有不同难度，对应不同等级奖励分，最终比较分数高低。
- 召集作为现代副本开启背景；同门同行本 PR 只留叙事伏笔，不实现远征队伍或其他流派 AI；本流派每代两人的身份、收徒和传承必须在本 PR 实现，不能用“同行留待以后”省略第二人。

## 4. 两人一代的师徒传承与道术分层

本节按最新设定替换第一版的家族血缘和唯一命定者方案，其优先级高于尚未实装的旧计划。每代两人是代次结构，不是所有在世门人总共只有两人；师父、当代同门与下一代徒弟可以同时在世。

### 4.1 师徒谱系与私人生活

门派拥有稳定身份、信物、道法改进记录、气运和传承成果；每代有两个传人席位，每位师父一生只招收一名正式徒弟，该徒弟属于下一代。记录 generationId、两个席位、masterId、discipleId、正式入门状态与交接状态。不得把 household.heirId 或 childId 直接当作师徒关系，也不得只把“孩子”文本改成“徒弟”。

实施默认：玩家可在当代两人之间选择行动者，每个人有独立年龄、健康、时间、精力、修为和所学；共用的物资、设备与气运按实际占用结算一次。新季不会因切换行动者刷新预算，季末不能由第二个人再次触发。下一代每人由对应师父培养，作为真实人物存在，不是交接时凭空生成的成年人。

收徒是明确行动，展示师父名额、候选人的年龄与资质、入门成本。默认按两席逐次收徒，未收满时显示空缺而非生成第三人。候选人生成后固定，拒绝、刷新或换行动者不能免费重抽。收徒不要求结婚或生育，个人可以终身不婚育；私人家庭成员不占传人席位、不自动取得信物或修道身份。本 PR 不新建婚恋系统；既有生育若保留为生活过程，须与门派招徒、继承和失败条件完全解耦。

### 4.2 换代、死亡与时代切换

默认在下一代两名弟子均满足公开的接班条件后完成整代交接，每代计数只增加一次；不能先接一个席位就令时代驻留代数增加两次。前代仍在世时可作为师父教导，但不无限扩大可直接行动的成员数。师父死亡不抹除已收徒弟及其学习结果，也不能通过死亡释放第二次收徒名额。

空缺处理的实施默认：师父尚未收徒便死亡，该席位中断；展示中断原因，允许现存门人继续本代修行和现代任务，但不能宣称已经完成完整换代。无人能够继续行动时结束；不自动从亲生子女、配偶或陌生人中补位。是否以后允许特殊补位属于新机制，不在本 PR 默认为允许。

跨时代只改变社会条件，不替换门派谱系、不自动生成新传人、不重抽资质，也不清空同一个人的修为与知识。实际新入门者与同一个人进入新时代必须区分。保留时代公共服务与阶段回报，修订现行按生育年龄估算剩余代际时间的逻辑，不能再用距生子时间推算收徒和交接。

### 4.3 道：个人修行与门派永久改进

“个人修为”和“门派道法水平”是两份不同状态：前者由每人从零修炼，后者记录历代对修炼方法的永久改进。开局、收徒、换代都不得把师父的修为复制给徒弟；教学可以帮助学习，但必须付出双方真实时间和精力。术的课程仍由个人按前置学习，不因入门或道法提升而自动掌握。

修道闭环：玩家看到心法、个人修为、下一阶段条件及实际效果 → 投入时间与精力进行冥想/修习 → 获得个人进度并达到阶段 → 改善本人其他行动效果 → 换人后新传人仍从零开始，但使用已经改进的门派方法。

默认将道的作用做成统一且有上限的效果计算层，接入现有行动报价与结果。学习/研发提高进度或效率；劳动/生产改善实际效率或产出；教导提高传授效果；休养改善恢复；采购/协调改善本人执行成本；副本改善本人步骤效率。所有有实际成本或结果的行动逐项列出适用项，无关的切页、保存、终局计分不套倍率。道不会突破原料守恒、设备能力、库存和前置要求；不能直接倍增最终得分、复制买卖物资、凭空改变天赋；概率仅通过第 5 节的气运衍生效果小幅影响。

门派改道闭环：个人达到高修为并有跨领域实践证据 → 投入较多时间与资源研究/验证心法 → 经过多个实际步骤形成突破 → 更新门派道法版本及永久效果 → 现存与未来门人依个人修为受益。默认用高门槛、有限进度和实际验证体现“很难”，不只靠低概率抽奖；不能单次抽卡直接升级本门道法。

默认效果关系为 E = 1 + B(d) × P(x)，d 为门派道法水平，x 为个人修为，P(0)=0；B、P 有公开上限。因此改进方法永久有效，但刚入门仍需要亲自练习才能兑现效果。具体行动使用减成本还是增进度逐项确定，不能两边重复乘倍率。每次改进记录贡献者、验证证据与版本，后续门人不能重新领取同一改进成果。

## 5. 道的次要衍生效果：气运与机遇

本节取代早期“所有成长成果发气运、以抽卡驱动成长”的方案。主线是修道习术及艰难的永久改道，气运只是修行后对机缘的小幅影响。它不拥有独立等级、技能树、刷取任务或气运专属养成循环，信物不再是与道并列的独立力量源头。

### 5.1 派生来源与消耗边界

实施默认：个人首次完成有效修道阶段时，依其修为与门派道法产生少量气运，进入有上限的共享机缘储备。记录「人物 ID + 修道阶段」去重；同一人物重复修习、切换行动者、换季或跨时代不反复领奖。新弟子从零修行，可以在实际完成阶段后获得对应份额，不能靠收徒/退出重抽奖励。普通学习、生产、采购不直接发气运；实践成果用于道的验证条件，兼顾善行的额外奖励优先表现为真实学习、教导或修行进度，而非所有行为兑换抽卡货币。

消耗的是气运储备，不是个人修为或门派永久道法。抽卡后不倒退修为，不削弱道对日常行动的确定性效果；余额为零也能正常修道、学术、授徒和完成兜底任务。储备及领取记录可以跨代保留，但新传人仍须亲自修炼，不能靠继承余额获得高修为效果。卡牌不增加气运收入、回复速度或修道阶段奖励。

### 5.2 概率方案

实施默认：抽取前读取余额 F，并计算由行动者修为 x、门派道法 d 决定的衍生强度 H(d,x)，H 有明确上限且新入门时为零。有效机缘强度 q = min(clamp(F / Fmax, 0, 1), H(d,x))。各结果概率在基础概率附近按 q 小幅偏置并归一化；公布基础概率、修道带来的偏置和最终概率，不让稀有卡收益超过正常修行的主体收益。

这使气运同时受修道水平与已消耗储备约束，不能靠囤积气运跳过修行。抽取按扣费前状态报价并原子扣费；门派保留的道法只有通过个人修习才能产生衍生作用。参数仍待数值阶段落实，必须保证概率合法、偏置有限、基础概率可用；不把气运余额变成决定后继弟子是否可用的门槛。

### 5.3 弟子资质与季节机遇

招徒首先保证基础候选池可用，资质决定不同擅长方向，正常培养始终有效。招徒机遇仅按招徒师父的修道衍生效果小幅偏置候选分布，不消耗气运、不改写已生成人物资质，也不要求先抽卡。职业类型、性别和肖像不按好坏统一排序。候选人一经生成即固定，刷新或换人不得免费重抽。

少量学习启发、生产协助、教导心得也可受修道衍生机缘影响；默认每季至多一次，不做独立日常刷取系统。季初固定当代两人的道衍生效果快照，以有上限的平均值作为共享季节机缘依据，避免切换行动者挑选开奖状态；季末公布结果，对下一季提供小幅辅助。道的确定性效果与随机奖励不得重复结算。

观察、切页、存档和导出不消耗随机数；相同初始状态与行动序列得到相同结果，不暴露未来结果或内部种子。气运不改变天气生成器，不重抽已经发生的事件。

## 6. 可选机缘：消耗衍生气运抽卡

抽卡入口放在修道详情的次级位置，不与道、术并列为主导航。卡牌只提供有限辅助；不抽卡也必须能形成完整成长与副本兜底路线。玩家看到当前修为、衍生效果、余额、抽取成本、三档概率、可获得效果与重复卡处理 → 选择抽取 → 同一步中校验余额、扣除气运、推进随机状态、发放卡牌和事件 → 剩余气运与已获传承卡跨代保留。

默认单一常驻卡池，不增加付费货币、十连、保底或卡池轮换。卡牌围绕学习、生产、授徒、筹备四类能力，第一版每类至少有一个实际生效的效果；具体效果只增强现有行动，不凭空完成副本、不直接给分、不增加气运获取倍率。

默认卡牌为可继承的传承成果，同名卡升级至有限等级，满级重复转为有上限的普通经营补给，不返还气运或抽取次数。每个效果写明生效对象、叠加方式与上限，特别检查学习成本与精力成本不能被减为负数，生产收益不能绕过投入、设备与人力条件。

余额不足时行动禁用并说明原因。抽取结果持久化，刷新不会再次发牌；拒绝的行动不扣气运、不推进随机数。所有资源成本只扣一次，避免行动公共支付与专有执行过程重复扣费。

## 7. 现代召集、危机与难度评分

### 7.1 阶段与任务开启

现代前显示潜龙积累，必要的技术实践属于见龙范围；不限制正常学习与生产。进入现代时信物召集只触发一次，自动开放危机任务与准备期限，玩家可选择任务顺序和方案，但不能把未完成任务当作已完成使命。开启任务后进入飞龙阶段，不以一句提示冒充实际权限变化。

默认现代任务共享公开的有限准备窗口，期限在进入现代时确定；这是替换现行“现代无限代、主动结束”的新规则。期限参数在数值阶段确定，并在进入现代前预告。提前结算需展示未完成任务与预期结果；到期或传承结束时结算已有成绩，未完成必需任务则使命失败。前现代沿用现有时代驻留限制，不通过本 PR 顺便重做全部时间系统。

### 7.2 首版危机目录

| 副本方向 | 玩家解决的问题 | 可复用的能力与投入 |
| --- | --- | --- |
| 智能系统失控 | 恢复必要约束，保持关键公共服务可用 | 数学验算、组织协调、供能与设备保障 |
| 生物安全危机 | 维持防护、检测与生活保障，阻断系统性扩散 | 生产规程、材料设备、供水与粮食调配 |
| 核升级与战争危机 | 降低误判、支持核验和应急协作 | 数学、通信相关现有产品、组织与工程投入 |
| 生态与气候危机 | 在复合冲击下维持粮、水、能源的生存底线 | 农学、灌溉、储存、供能与持续生产 |

危机以公共安全、保障与协调任务表达，不引入武器设计、病原制造或真实技术操作模拟。题材应有不同的任务组合，不能仅替换同一交付清单的标题。若现行目录没有某项能力，优先选择已有能力组合，不以一个副本为由扩展整棵新学科树。

### 7.3 难度、方案与投入

每个副本默认三个难度：兜底、稳局、周全。分别表示完成最低存续使命、在更高约束下减少损失、兼顾更多长期后果；难度不是玩家主动制造更大灾难。

每一档列出知识或验证证据、实物/能源投入、本人时间精力及任务步骤。高难度至少增加一项能力配合或持续保障条件，不只把钱粮成本乘倍数。最低难度必须有不依赖稀有卡和特定天赋的稳定完成路径；卡牌与天赋改善效率或提供替代方案。替代方案在开局规则中定义，不能由文案临时裁定。

复用真实交付、数学验算、通电与电器验证等现有过程；物资交付真实扣除，知识证据不消耗，电力不得重复用于多个承诺。跨季任务记录实际投入和进度，换代不断档。任务失败是否保留已交付成果需按步骤明确，不能发生无提示的吞资源。

### 7.4 得分与防刷

默认总分 = 各副本已完成最高难度的奖励分之和。未完成一档不计该档分；低档完成后可以挑战高档，高档成功仅替换本副本原有成绩，不叠加低档分。重复完成同档不加分，不返还可套利奖励。已完成步骤能否抵扣高档投入，在任务报价中固定并显示，不随界面操作改变。

财富、卡牌稀有度、气运余额、阶段回报与存活季数都不直接计分。旧现代任务清单必须合并或替换为新任务步骤，不能保留第二条累计分入口。成功条件默认为所有必需危机至少完成兜底档，高分来自更高难度。

成绩界面显示总分、各副本难度与贡献、完成/失败原因、规则版本与起始场景。首版只做本局成绩及现有存档内保存，不建联网排行榜、反作弊或跨世界公平排名服务。不同起始条件的比较限制应明确，公开观察仍不泄露种子。

## 8. 结算顺序、存档与公开观察

建议在现有领域状态内显式区分门派数据与私人家庭数据，避免新建 runtime 系统。将师徒谱系、两人预算、个人修为、门派道法改进、气运、卡牌、证据领取记录、候选人资质和副本成绩纳入存档；按照 `AGENTS.md` 不迁移旧档。加载缺少必要新结构的旧档应明确失败并保留原文件，不能填默认值伪装成兼容。继续 0.27.0；如必须升规则或 schema 版本，先说明原因并取得授权。

即时行动遵循：校验可用性 → 一次性支付 → 执行动作/抽取 → 记录实际成果 → 结算修道进度及去重后的衍生气运 → 原有条件触发季末。卡牌取得本身不触发成长奖励。

季末须在现行 `systems/time.ts` 上画清调用顺序并实现：原有生产与生活结算 → 依据实际成果结算奖励 → 依原有生命顺序处理人物老化、私人生活与师徒交接 → 季度机遇结算 → 副本步骤及期限检查 → 若仍继续则进入新季。招徒候选人按生成行动时招徒师父的修道衍生效果小幅调整分布并保存；私人家庭生育不消耗或分配门派席位。季初当代两人衍生效果快照只用于该季机遇。若与现有调用位置冲突，调整前写明最终顺序，避免季末被调用两次导致双倍奖励。

观察必须能回答：当代两人分别是谁、各自弟子与修为、门派道法水平及改进来源、气运为什么变化、抽卡成本与概率是多少、卡牌实际效果是什么、下一次招徒候选生成将受什么影响、现代还剩多少季、各任务缺什么、最终分数从哪里来。网页和 AI 共用同一行动接口与报价；不暴露随机状态、未来天气、预抽结果或内部种子。

## 9. 数值实施方法

按顺序逐组落数，不同时重调工资、物价、产量与气运。先设个人修道、术的学习与永久改道节奏，确定不依赖抽卡的副本兜底路线及期限，再给气运的小幅偏置、有限储备和辅助卡牌留出较小收益空间。抽卡收益不能反过来决定主线成长预算。

每组在提交说明中写清假设与粮、时间、钱、传承的副作用。基本约束为：概率合法且总和为 1；高气运确实改善好结果概率但不保证成功；正常修行可获得少量可选抽取；低气运仍能继续成长；有限卡牌上限不会消灭成本；副本高档得分严格高于低档；有限期限内存在完全不抽卡的兜底路线。

新增参数进入现行 v27 对应 JSON，并补齐类型、加载和范围校验；既有 bounds 不擅自扩展。不要通过改变原有公式掩盖抽卡或副本数值失衡。不跑千局、不建自动调参或付费模型循环。

## 12. 本轮实际实施口径

P1—P5代码与文案已落地，勾选表示实现完成，不等同于第11节所有长程场景均已验收。最终公式见 CURRENT_GAMEPLAY_V27.md；以下实际选择覆盖前文建议中的可选方案。

- 修道每次4时间/2精力得2进度，每8进度一境、上限5境。首次亲自学习及有效授业各得1进度；气运只在个人首次破境发放3点，上限30。
- 永久心法最多4级，要求满境、4×下一等级课程、三个学科及两类亲身实践（耕作/生产/授术）；每级八次付费研证，每步6钱。公共资产或雇员成果不能替代个人实践记录。
- 本人道每境降低4%成本，永久心法每级再加每境1%，个人封顶35%；卡牌及季度机缘合计后封顶40%，正成本最低0.25。员工成本不受影响，季末本人劳动采用一致公式。电灯每季首次供能为当代两人各加2时间。
- 抽卡6气运，四类辅助各封顶三级、每级1%减耗。基础概率80/18/2；令q=min(气运/30,本人道效果)，概率为80%-10%q、18%+8%q、2%+2%q。满级溢出转有限粮食，不返还气运。
- 每位师父只有一位固定候选；候选16岁，正式入门才进入生活与年龄结算。私人婚育不进入模拟，不婚育不阻断传承。两位弟子成年才整代交接。
- 季末顺序：原有生产并记录个人实践 → 生活消耗 → 远期工程及回报 → 老化/死亡及传承状态 → 季度机遇 → 时代/危机期限 → 若继续则季初恢复与机遇快照。耗尽个人预算不会自动结束季度。
- 现代240季，四类必需危机各有技术/协调路线、三级难度、方案/投入/跨季验收三步骤。基础交付4×难度、协调费8×难度；每副本只保留10/40/90最高成绩。高档需重新投入，步骤成果不转作下一档抵扣。四类至少兜底才成功，副本外不计分。
- 无卡兜底不检查气运、卡牌、永久心法或电气设施；技术课程与材料、或组织课程与委托提供不同路径。零卡全程耗时及完整经济平衡仍须实际长程验收。
- 状态使用现行模块并保留0.27.0；缺失新结构的旧档拒绝加载，原文件保留。不新增测试、实验、试玩记录或迁移脚本。

交付仍保留草稿状态，直到第11节完整闭环验收完成。构建及短时页面核验不替代永久改道、整代交接、三级任务、期限与死亡边界的专项验证。
