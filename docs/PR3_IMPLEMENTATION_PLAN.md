# PR3 实施计划：家族气运、命定传承与现代使命

## 1. 目标与使用方法

玩家目前可以经营、学习和交接，但门派背景尚不影响选择；跨时代会换成无亲属关系的新家族，现代终局仍是余粮、传动轴和通电等任务的单一清单。本 PR 要把已确定的主题落实为完整循环：**发展家庭能力 → 跨代积累 → 消耗气运争取机缘 → 现代承担危机任务 → 按副本难度与成果计分**。

本计划随 PR3 第一笔提交交付。基线为 PR2 合并后的 `main`（`fb72f0a`），规则 0.27.0。实施前核对实际代码，按阶段推进并更新清单；不能以增加背景文案或展示不可操作的界面代替机制完成。

第 2 节是用户已经确定的要求；其余章节的具体公式、卡池、难度与节奏是本计划提出的**实施默认方案**，不是用户此前逐项确认过的规则。实施者可以根据现行模块作局部调整，须同步本计划说明原因，不能改变第 2 节。数值越界、规则升版等仍按根 `AGENTS.md` 处理。本次仅编写计划，不在文档提交中实施机制。

## 2. 已确定的创作与玩法要求

- 虚构流派奉行墨家兼爱、非攻，因墨家失败而吸收鬼谷一脉隐世、韬光养晦的处世思想。门人化整为零，以家庭为单位独立发展，紧跟时代前沿。
- 门派只在人类处于灭绝边缘时出手兜底；局部灾荒即使造成大量死亡，也不自动触发门派任务。平日观察、思考、修身与积累。
- 提升自身能力是主线。偏离主线的事不获得奖励；兼顾善行与能力成长时有额外奖励。允许一时自私，但恪守无私信念。
- 平日「潜龙勿用」，有限施展至多「见龙在田」；进入现代、开启必须解决的副本后才「飞龙在天」。
- 信物赋予家族力量，每代有且仅有一位命定之人。其决定影响家庭气运，气运影响好运与下一代天赋。代价是始终与门派相连，能被门主找到。
- 气运在现代以概率分布偏置解释。这是借量子概率意象构造的虚构规律，不将宏观好运描述为现实波粒二象性的已知结论。
- 奖励可采用抽卡；抽卡消耗气运，气运影响抽卡概率。
- 人类认知与约束力量的能力落后于其破坏能力。现代危机涉及 AI 与生物技术滥用、核升级与世界大战、环境与气候系统性风险。
- 现代副本是必须承担的事，也是最终分数唯一来源。同一副本有不同难度，对应不同等级奖励分，最终比较分数高低。
- 召集作为现代副本开启背景；同门同行本 PR 只留叙事伏笔，不实现队伍、其他家族 AI 或门派管理。

## 4. 家族、命定之人与跨时代传承

### 4.1 状态与身份

在家庭状态中保留稳定的传承身份与信物、当前气运、已领取成长证据、卡牌拥有情况；在人物上记录所属代次与命定身份。避免与已有经营者、后辈、家谱信息建立两套互相矛盾的主键。

实施默认：沿用当前单后辈链，每个出生代次指定该后辈为命定之人；开局经营者与既有后辈分别归属不同代次。前代退休后可以仍在世，下一代也可以在成长，但只有当前经营者能够执行本代决策和抽卡。“每代唯一”不等于“全家同时只能活着一位命定之人”。不新增兄弟分家、收徒继承或可重复重选继承人。

### 4.2 换代与时代切换

玩家能看到命定身份、继承人是否可接手、保留内容 → 安排既有交接行动 → 季末由真实成年后辈继承 → 家庭信物、气运、卡牌与成长证据延续。个人知识不凭空复制；已有教导、家族记录与学习优惠仍有效。

默认取消时代切换时生成无亲缘随机家族的行为：**跨时代只改变社会条件，人物与家族继续生活**。时代转换不自动增加一代、不重抽当前人的天赋、不清空已学个人知识。只有实际人物交接增加代次；社会的驻留代数以进入该时代时的代数重新计量。保留各时代现有公共服务及阶段回报，复核连续知识带来的学习节奏变化。

前代死亡有成年后辈时沿用可交接状态；没有可接手成年后辈时沿用结束规则，不凭空补成年人。使命尚未完成按未完成结算；现代已获得的合法分数可以展示，但不能伪装为使命完成。

### 4.3 保留表

| 内容 | 同时代换代 | 跨时代 |
| --- | --- | --- |
| 信物、气运、卡牌、领取记录 | 保留 | 保留 |
| 人物天赋 | 已出生者不重抽 | 不重抽 |
| 个人知识 | 后辈使用自己的学习结果 | 同一人物继续保留 |
| 家产、规程、家谱 | 沿用现有合法传承 | 保留，社会服务按新时代更新 |
| 经营安排 | 沿用既有交接后接续规则 | 按社会条件重新校验 |
| 副本进度与最高成绩 | 保留，不按代重置 | 现代前不生成可得分任务 |

## 5. 气运收入、随机事件与后代天赋

### 5.1 来源：奖励可验证的成长

默认只对实际成果发放气运：首次掌握课程、首次完成产品验证或系统调试、首次将已掌握知识教给后辈。气运不替代这些行动本来的知识或生产收益。将成果键持久化，例如「传承身份 + 成果类型 + 课程/产品 ID」；领取范围默认全家族一次，不能通过换代、时代切换或读界面重复领取。

兼顾善行的最小落地为既有教导中的有效传授：实际让后辈学会内容、提升家庭后续能力时，除对应成长奖励外再有明确的善行加成。单纯点击教导而没有新增成果不领奖。后续可扩展公共技术分享，但本 PR 不新增以救灾为日常主线的系统，不对休息、采购或重复劳动机械发放气运。

气运是非负、有上限的家庭资源；达到上限时显示溢出规则。每次变化记录来源、增减量与余额。卡牌获得或被动效果不直接生成气运；抽卡获得的物资本身不算首次生产，必须经过真实行动产生对应成长证据。

### 5.2 概率方案

默认按行动执行前的气运余额 F 计算概率，再原子扣费并抽取。设气运上限为 Fmax，幸运强度 q = clamp(F / Fmax, 0, 1)。卡牌按「基础、进阶、稀有」分档，以两端合法概率表线性插值得到 p(q)；两端各档概率之和必须为 1，所有概率非负。不同稀有度决定奖励强度，不直接改变最终分数。

数值阶段再填写 Fmax、抽卡成本、两端概率与各成果收入。界面及 AI 使用同一报价结果，不各自重写公式。气运消耗既降低余额，也影响下一次抽取和未来出生；这是需在行动前明确告知的取舍。已出生者不受之后气运变化影响。

天赋沿用现有职业特质类型，并增加受气运影响的品质或强度层，避免把学者、强壮等不同路线简单排序为好坏。职业类型保留多样性，气运只提高较高品质概率。品质作用于已有学习、体力、教导或组织效果，有明确上限；不赋予未学知识。出生时抽取一次并终身固定，性别和肖像不参与能力权重。

### 5.3 最小随机事件

接入少量成长机遇，例如学习启发、生产协助、教导心得；不扩成独立剧情系统。默认每季至多结算一次，按季初气运快照影响当季好运概率，在季末公布结果并作用于下一季。气运不更改天气发生器，不重抽已发生事件，不提供随机状态或未来结果预览。

每个结果需有真实用途、持续时间或领取条件；无条件可用的成长路线仍由日常学习与生产提供。观察、切页、存档和导出不消耗随机数；相同初始状态与行动序列得到相同结果。该规则保证可复现，不承诺离线存档无法被复制或回退。

## 6. 消耗气运抽卡

玩家看到当前余额、抽取成本、三档概率、可获得效果与重复卡处理 → 选择抽取 → 同一步中校验余额、扣除气运、推进随机状态、发放卡牌和事件 → 剩余气运与已获传承卡跨代保留。

默认单一常驻卡池，不增加付费货币、十连、保底或卡池轮换。卡牌围绕学习、生产、养育、筹备四类能力，第一版每类至少有一个实际生效的效果；具体效果只增强现有行动，不凭空完成副本、不直接给分、不增加气运获取倍率。

默认卡牌为可继承的传承成果，同名卡升级至有限等级，满级重复转为有上限的普通经营补给，不返还气运或抽取次数。每个效果写明生效对象、叠加方式与上限，特别检查学习成本与精力成本不能被减为负数，生产收益不能绕过投入、设备与人力条件。

余额不足时行动禁用并说明原因。抽取结果持久化，刷新不会再次发牌；拒绝的行动不扣气运、不推进随机数。所有资源成本只扣一次，避免行动公共支付与专有执行过程重复扣费。

## 7. 现代召集、危机与难度评分

### 7.1 阶段与任务开启

现代前显示潜龙积累，必要的技术实践属于见龙范围；不限制正常学习与生产。进入现代时信物召集只触发一次，自动开放危机任务与准备期限，玩家可选择任务顺序和方案，但不能把未完成任务当作已完成使命。开启任务后进入飞龙阶段，不以一句提示冒充实际权限变化。

默认现代任务共享公开的有限准备窗口，期限在进入现代时确定；这是替换现行“现代无限代、主动结束”的新规则。期限参数在数值阶段确定，并在进入现代前预告。提前结算需展示未完成任务与预期结果；到期或家族结束时结算已有成绩，未完成必需任务则使命失败。前现代沿用现有时代驻留限制，不通过本 PR 顺便重做全部时间系统。

### 7.2 首版危机目录

| 副本方向 | 玩家解决的问题 | 可复用的能力与投入 |
| --- | --- | --- |
| 智能系统失控 | 恢复必要约束，保持关键公共服务可用 | 数学验算、组织协调、供能与设备保障 |
| 生物安全危机 | 维持防护、检测与生活保障，阻断系统性扩散 | 生产规程、材料设备、供水与粮食调配 |
| 核升级与战争危机 | 降低误判、支持核验和应急协作 | 数学、通信相关现有产品、组织与工程投入 |
| 生态与气候危机 | 在复合冲击下维持粮、水、能源的生存底线 | 农学、灌溉、储存、供能与持续生产 |

危机以公共安全、保障与协调任务表达，不引入武器设计、病原制造或真实技术操作模拟。题材应有不同的任务组合，不能仅替换同一交付清单的标题。若现行目录没有某项能力，优先选择已有能力组合，不以一个副本为由扩展整棵新学科树。

### 7.3 难度、方案与投入

每个副本默认三个难度：兜底、稳局、周全。分别表示完成最低存续使命、在更高约束下减少损失、兼顾更多长期后果；难度不是玩家主动制造更大灾难。

每一档列出知识或验证证据、实物/能源投入、本人时间精力及任务步骤。高难度至少增加一项能力配合或持续保障条件，不只把钱粮成本乘倍数。最低难度必须有不依赖稀有卡和特定天赋的稳定完成路径；卡牌与天赋改善效率或提供替代方案。替代方案在开局规则中定义，不能由文案临时裁定。

复用真实交付、数学验算、通电与电器验证等现有过程；物资交付真实扣除，知识证据不消耗，电力不得重复用于多个承诺。跨季任务记录实际投入和进度，换代不断档。任务失败是否保留已交付成果需按步骤明确，不能发生无提示的吞资源。

### 7.4 得分与防刷

默认总分 = 各副本已完成最高难度的奖励分之和。未完成一档不计该档分；低档完成后可以挑战高档，高档成功仅替换本副本原有成绩，不叠加低档分。重复完成同档不加分，不返还可套利奖励。已完成步骤能否抵扣高档投入，在任务报价中固定并显示，不随界面操作改变。

财富、卡牌稀有度、气运余额、阶段回报与存活季数都不直接计分。旧现代任务清单必须合并或替换为新任务步骤，不能保留第二条累计分入口。成功条件默认为所有必需危机至少完成兜底档，高分来自更高难度。

成绩界面显示总分、各副本难度与贡献、完成/失败原因、规则版本与起始场景。首版只做本局成绩及现有存档内保存，不建联网排行榜、反作弊或跨世界公平排名服务。不同起始条件的比较限制应明确，公开观察仍不泄露种子。

## 8. 结算顺序、存档与公开观察

建议在家庭状态内承载新增数据，避免新建 runtime 系统。将气运、卡牌、证据领取记录、出生结果和副本成绩纳入存档；按照 `AGENTS.md` 不迁移旧档。加载缺少必要新结构的旧档应明确失败并保留原文件，不能填默认值伪装成兼容。继续 0.27.0；如必须升规则或 schema 版本，先说明原因并取得授权。

即时行动遵循：校验可用性 → 一次性支付 → 执行动作/抽取 → 记录实际成果 → 领取去重后的气运奖励 → 原有条件触发季末。卡牌取得本身不触发成长奖励。

季末须在现行 `systems/time.ts` 上画清调用顺序并实现：原有生产与生活结算 → 依据实际成果结算奖励 → 依原有生命顺序处理老化、出生和交接 → 季度机遇结算 → 副本步骤及期限检查 → 若仍继续则进入新季。出生采用到其结算时已确定的气运余额；季初事件概率快照只用于该季机遇。若与现有调用位置冲突，调整前写明最终顺序，避免季末被调用两次导致双倍奖励。

观察必须能回答：谁是当前命定经营者、气运为什么变化、抽卡成本与概率是多少、卡牌实际效果是什么、下一次出生将受什么影响、现代还剩多少季、各任务缺什么、最终分数从哪里来。网页和 AI 共用同一行动接口与报价；不暴露随机状态、未来天气、预抽结果或内部种子。

## 9. 数值实施方法

按顺序逐组落数，不同时重调工资、物价、产量与气运。先从现有正常学习和换代节奏估计可获得的成长证据数，再设抽取成本与气运上限；随后设卡牌效果与天赋品质，最后确定副本需求、期限和奖励分。

每组在提交说明中写清假设与粮、时间、钱、传承的副作用。基本约束为：概率合法且总和为 1；高气运确实改善好结果概率但不保证成功；正常发展能承担适量抽取；低气运仍能继续成长；有限卡牌上限不会消灭成本；副本高档得分严格高于低档；有限期限内存在无稀有卡的兜底路线。

新增参数进入现行 v27 对应 JSON，并补齐类型、加载和范围校验；既有 bounds 不擅自扩展。不要通过改变原有公式掩盖抽卡或副本数值失衡。不跑千局、不建自动调参或付费模型循环。

## 10. 分阶段交付

- [ ] **P1 传承基础**：状态、开局、出生、交接与跨时代连续性；家人观察及页面能解释保留内容。
- [ ] **P2 气运与天赋**：实际成长证据、奖励去重、善行加成、出生品质、季节机遇及结果反馈。
- [ ] **P3 抽卡闭环**：成本与概率报价、原子抽取、卡牌实际效果、叠加上限、重复卡及保存恢复。
- [ ] **P4 现代副本闭环**：召集、四类危机、三级难度、实际投入、准备期限、最高成绩与终局结算。
- [ ] **P5 一致性收尾**：桌面入口、帮助、AI 精简观察、玩法说明与本计划同步，清除已经过时的规则文案。

每阶段内部遵循 `model → systems（含 time.ts）→ actions → observation → rulesets/v27 与 bounds → apps/board → compact-observation`。后续提交按阶段提供可审阅的因果链，不把整个 PR 堆成一笔无法核对的代码提交。首笔计划提交始终保留为审阅基线。

## 11. 验收与完成条件

以下是验收场景清单，不授权新增或主动运行 `tests/` 测试。实现阶段按仓库规则做相关桌面页面短时核验；需要长程或专项测试时由用户明确指定。未实际验证的场景如实标注，不以读代码冒充试玩通过。试玩不落记录、截图或报告文件。

| 场景 | 应满足的结果 |
| --- | --- |
| 新开局、后辈出生、真实交接 | 每代唯一命定身份；出生天赋一次性固定；交接保存气运与卡牌 |
| 时代切换 | 家族和人物连续，不生成无亲缘替代者，不重抽天赋或复制后辈知识 |
| 首次学习、有效教导、重复操作 | 实际成果领奖，兼顾教导有额外奖励；重复成果和纯切页不领奖 |
| 抽取及余额不足 | 显示正确概率；成功只扣一次并发一次，失败不扣资源或随机数 |
| 满级重复卡与最低行动成本 | 不产生气运循环、不出现负成本、不绕过设备或材料约束 |
| 保存后重开及无效旧档 | 状态与已领记录保持；不重发奖励；失败加载不覆盖原档 |
| 现代前与进入现代 | 现代前无终局分数；现代只召集一次，期限与任务可见 |
| 同档重做、低档升高档 | 同档不刷分；升档只替换本副本成绩，历史任务不另加分 |
| 无稀有卡、不同成长路线 | 有稳定兜底路径，至少两种不同能力组合能发挥实际用途 |
| 提前结束、到期、人物死亡 | 结算分数合法，使命完成与否明确，结束后不可继续领奖 |
| 网页与 AI 观察 | 成本、概率、阻碍和分数一致，不泄露随机状态与未来结果 |

PR 可转为待合并状态的条件：P1—P5 全部完成；新开局能通过统一行动接口走完成长、抽卡、传承、现代任务和评分的实际闭环；说明与实现一致；没有把规划内容当作已上线功能。验证范围和未覆盖风险写在 PR 描述中。不得因只完成背景或卡牌界面就宣称整个 PR 完成。
