# 0.24.0 全领域学科分叉

0.18 已把力学、材料学改成根节点后分叉。本版对农学、生产组织学和数学做同样处理：下游只挂自己那一支，并且解开真实行动。

## 结构

```
农学 A0 基础栽培
 ├─ A1 田间水分 → A2 井渠（仅农业阶段）
 ├─ A3 土壤肥力 → 施肥
 └─ A4 油料与纤维 → 大豆、亚麻

组织 O0 劳动分工
 ├─ O1 生产工序 → 工匠/农工、轴加工
 └─ O2 采购与交付 → 补货、销售、契约

数学 Q0 基础数学
 ├─ Q1 应用数学 → 加工减负、副本验算
 └─ Q2 账目与计量 → 时代生产课前置
```

力学、材料学不变。时代课 O3/O4/O5 的数学前置改为 Q2；O5 仍挂 O2，因 O2 不再经过 O1，现代调度可走商贸线。

## 结算

- 小麦仍要 A0；大豆/亚麻要 A4。施肥要 A3。
- 普通雇工仍要 O0，工匠/农工要 O1。有 O2 不等于有 O1。
- 学习仍只查知识前置，不耗样品。
