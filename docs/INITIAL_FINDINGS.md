# 初次实验记录 · 2026-09-10

规则版本：0.1.0。本记录只讨论预研原型，不是正式玩法平衡结论。

## 做了什么

- 13 项相关测试：动作纯转换、前置与来源、设施作用、季末、生活失败、真实交接、跨代项目、观察隔离、存档重放及少量完整流程。
- 基线与 `trainingCost=0` 候选对照：种子 7、17；河渠、缺水两个场景；生活、水利、种源、传承四个脚本策略。共 32 个短实验。
- 使用的是可解释脚本策略，不是大模型。所有实验达到两代观察终点，没有生活缺口。
- 原始结果在 `reports/initial-comparison/`；每局保留 replay 与 trace，可以重新检查。
- 命令行实际验证了开局、提交学习与重新观察：revision 从 0 到 1，行动点从 3 到 2。
- 浏览器短时试玩验证了学习不直接掌握、实践后解锁、末点行动自动季结与刷新恢复；桌面排版已查看。

## 有证据的观察

| 观察 | 具体结果 | 目前能得出的结论 |
| --- | --- | --- |
| 无技术路线的钱财很多 | 基线生活策略期末钱财为 66—86；水利为 18—27，种源为 14—38 | 当前工资与市场条件可能掩盖技术投资的经济意义，不能直接认定科技无用 |
| 降低实践费用没有增加学习广度 | 所有配对实验学会节点数变化为 0 | 在这些策略与窗口内，现金实践成本不是决定学会数量的瓶颈 |
| 免费实践主要增加剩余钱财 | 水利策略每局多 5 钱财，传承策略多 2 钱财；其他策略无钱财变化 | 候选改变了现金余额，但没有证明改善成长体验 |
| 水利改变了缺水下的处境 | 缺水基线中生活策略期末口粮均为 2，水利策略均为 8 | 设施确实在模型里改变生产；还需评估投入回报、闲暇与风险，不能只看余额 |
| 传承产生差异 | 传承策略交接时掌握 3 个节点；水利 2 个；种源 1—2 个 | 教学与自身成长存在可见取舍，仍未证明成本合理 |
| 种源项目确实能完成 | 种源策略每局取得 2 次样本并掌握定选 | 多季流程可达，不代表两季样本足以模拟真实育种 |

## 暂不采纳候选

免费实践只改善现金余额，没有显示更多可行学习路径。保留 `trainingCost=1` 作为原始基线，不自动修改。由于没有采纳候选，本轮不扩大到更多种子或全面回归。

## 下一步研究假设

1. **世界机会约束比学习费用更重要。** 目前做工始终能按固定工资成交，粮食也无限供应。下一轮应先选择“季节性岗位数量”或“局部粮食供应”中的一个机制，避免同时改多个市场变量。保持基本可玩出口，检验技术是否在具体环境中产生替代价值。
2. **观察窗口可能偏向短期收入。** 用一组略长的观察窗口检验建设和传承的回收期，而不是直接提高所有技术产量。
3. **控制策略可能不会利用研究信息。** 目前脚本只比较历史样本总量，未做气候适配。下一步可让真实 AI 读同一份报告，给出保留或替换种源的理由，再比较其后果。
4. **家学材料在有免费教师时意义偏弱。** 应单独比较“当地教师离开，但家庭有材料／无材料”的场景。不要把材料直接改成免费技能来制造价值。

这些只是下一轮提议，不属于已实施规则。先讨论采用哪个假设，再安排小批量实验。
