# 学科与产品设计基线

确认日期：2026-09-12。首期已接入规则0.9.0；实际实现范围、36课题与验证见 [当前规则说明](DISCIPLINE_ECONOMY_V9.md)。下文保留完整目标目录，其中未接入项在产品页明确标为规划。

## 首期范围

- 学科各自独立进阶，先展示主干进展与节点目录。学科内子分支后续开发；下表的排列不自动构成全部节点的强制串行前置，具体学习条件在实现时另行定义。
- 产品按用途与效果组织，成长关系只表达能力的发展，不表示配方原料或必须先制造前一产品。
- 产品需要的学科进展、制造熟练度、材料、加工条件与运行条件放在产品详情，不在学科或产品主图铺跨系统连线。
- 生产工具与消耗品分类后续开发。首期不依此分类建立额外页面或规则体系；具体产品的消耗、运行和磨损仍须按实际用途定义。
- 原料与部件单列配方目录；材料变体优先作为同一产品的不同配方，避免主图重复膨胀。
- 不以作坊升级作为主线。制造、研究、跨代继承及实际应用共同推动成长。校准仪、校准报告退出拟议新版工业主线，不再以测量仪器链作为共同门槛。
- 所有选择通过固定课题、配方、行动和可观察结果提供，不要求玩家自由填写目标、理论或研究内容。

## 实现与验证约束

先接通一个学科进展—产品制造—实际收益的完整循环，再逐步扩充。地区或时代变化由实际应用和传播触发，不由点亮学科自动宣布。科技胜利需独立确定核心节点集合，不能因规划目录扩张自动改变现行11/17条件。

实施规则变更时另增版本，保留旧实现、旧档和历史报告；所有行动由统一结算接口执行。模拟只读取观察，优先检查首次应用等待时间、重复实践成本、产品投入产出、传承成本和路线可达性。数值调整先存实验候选并进行必要的小批量对照；本次纯设计确认不运行测试或模拟。
