# 通用生产规则提案与实现边界 · 0.2.0

目标：让非农业家庭能够谋生，同一知识服务多个过程，同一需求存在替代技术路径。农业 0.1.0 保留为独立基线；本轮不是文明排名或完整人类历史。

## 因果关系

- 地区持有可采食物、木材、黏土库存。采集扣减当地库存；食物与木材按季恢复至容量，黏土在两代窗口内不恢复。恢复量受当前干旱影响，不预告未来天气。
- 家庭持有原料、商品、采集工具、已安装容器和最多一个制作项目。工作与交易受当季岗位、粮食、商品需求限制；每季补给表示外部地区供给，不表示凭空无限交易。
- 木作：2 木材，成形与装配各 1 行动，得到 1 木容器。采集工具：同样投入，成品可用 4 次，每次采木额外取 1 木材，仍受当地剩余量限制。
- 陶作：2 黏土、2 木材燃料，成形与烧制各 1 行动。成形后必须跨季干燥，再烧制得 2 陶器；已支付的原料和在制品跨代保留。首版不随机判废品。
- 工艺入门需要学习与实际制作。学过一次且有来源和前置即可受指导开工；掌握后可独立开工。继承者能完成已布置项目的常规工序，但不自动掌握设计知识。
- 储存：木作或陶作任一路线是储存配置学习的替代前置。装配一种容器花 1 行动、消耗 1 件商品，获得储存实践。基础保护 2 粮，木容器另保护 4，陶器另保护 6；每类最多安装一件。季末先吃粮，再损失未保护余粮的一半，向上取整。不是模拟所有食物都适合相同保存方式。
- 技术网络：环境观察、木作、控火不要求先学农业。控火是当前陶作路线的必要前置；已有测量经验可减少木作学习一次（最低一次），不构成必须前置。技术的必要依赖、替代依赖、有利经验分别展示。
- 老师按地区配置；外部交换提供有限的木作/陶作方法材料，使缺少本地老师的路线仍可接触。材料只提供学习来源，社会已出现、当地可接触、个人掌握、家庭有生产条件仍然分开。

以上成本和收益都是初始假设，参数候选放 experiments/；不因脚本完成或余额提高认定平衡。

## 首轮场景

林地聚落：木材与野生食物较丰富，黏土稀少，当地有木作教学。
黏土河谷：黏土较丰富、木材较少，有陶作教学和较多交换机会。
两者使用同一知识网络，不绑定国家、民族或文明能力加成。教师和资源是本次场景条件，不主张历史上的普遍分布。保留河渠、缺水环境供农业对照。

## 本轮未展开

未增加运输地图、人口职业分工、动态价格、冶金和机械。运输距离、社会组织、跨地区人员流动仍需独立结构实验。容器首版不磨损，采集工具会磨损；木材恢复是小规模可采材补充，不代表一季长成森林。基础石器、简易火源和耕作常识作为开局生活条件，不要求从零重新发明。

## 版本与迁移

- 工程 0.3.0，规则 0.2.0；旧 rulesets/traditional-agriculture.v1.json 与 tests/fixtures/legacy-v1.json 不变。
- 默认新局使用 rulesets/shared-production.v2.json。CLI --rules legacy 可新建旧农业局；不混入新机制。
- 原 formatVersion=2 存档继续严格检查实现指纹。显式 import 可将冻结工程 0.2.0、原始农业基线存档完整重放校验后复制到新 run ID；仍是规则 0.1.0，不转成新生产世界。其他实现/参数指纹拒绝猜测迁移。
- 浏览器使用新存储键，旧键保留；导入失败不覆盖当前存档。新生产规则必须另开新局，不承诺把旧资产快照转成新世界。
- 验证：8 条旧轨迹、接口保护、资源/工艺/储存/交换/传承因果测试，少量同配置固定种子脚本对照与桌面试玩。
