# 历史完整玩法 · 规则0.13.0 / 工程0.14.0

当前入口已更新至[现代版0.14.0](CURRENT_GAMEPLAY_V14.md)。本文保留运河版0.13.0实际执行的规则，供玩家阅读和后续设计讨论使用。核对日期：2026-09-13。本轮只整理文档，不改变规则、参数或存档，不运行新的模拟。历史实验与测试的结论范围单列于末尾。

## 1. 玩家身份、主目标与核心循环

玩家经营一个跨代家庭：本人拥有有限行动和个人知识，家庭拥有钱粮、田地、设备、人员与经营安排。世界按季推进，天气、资源恢复和市场供给会变化。

当前主目标是完成「两河大运河」五层文明试炼。它是一条逐层开放的建设链，没有战斗、怪物、随机掉落或地图探索。学科、农业、加工和贸易构成解决工程问题的手段。

核心循环：

> 保障家庭生活 → 获得知识、人员和设施 → 获取并加工物资 → 组织跨季供给 → 完成当前工程层 → 用保留的家业准备下一层 → 跨代接续。

玩家始终要处理五种限制：个人行动、可用钱粮、物料与在途时间、人员/设备能力、各系统之间的资源竞争。库存多、知识多、设备多，都不能单独替代整套系统的运行。

## 2. 一局如何开始与结束

| 项目 | 当前默认值与含义 |
| --- | --- |
| 开局家庭资产 | 6份即食粮、8钱、2木材、2黏土，三种作物种子各1 |
| 人物 | 本代经营者和已成年的后辈，个人学科初始为空 |
| 生产条件 | 一块空田，初始肥力2；无设备、雇员和作坊 |
| 个人行动 | 每季3点；大部分学习、劳动、建设、安排任务花1点 |
| 家庭生活 | 每季消耗2粮 |
| 时间窗口 | 每代16季、共3代48季；这是预研观察尺度 |
| 提前失败 | 连续3季缺粮，因困顿终止；充足供粮的一季会清除连续困顿 |
| 真正胜利 | 完成全部5层文明试炼，并通过当季家庭生存结算 |
| 未通关结束 | 48季窗口结束但未完成工程，显示试炼未完成 |

用完3点行动会自动结算本季；也可主动结束本季。编辑购物清单、作坊启停和工地供货等部分操作为0行动，不会自行推进世界。不要把“命令条数”当成“消耗的行动点”。

四个开局场景改变自然资源与市场条件，但当前不是四套独立科技路线：

| 场景 | 野食/木材/黏土初始上限 | 野食/木材通常每季恢复 | 市场口粮/临时岗位 | 天气特征 |
| --- | --- | --- | --- | --- |
| 河渠村落 | 3 / 5 / 20 | 1 / 1 | 8 / 1 | 干旱30%、丰水20% |
| 黏土河谷 | 3 / 5 / 20 | 1 / 1 | 8 / 1 | 干旱30%、丰水20% |
| 林地聚落 | 6 / 10 / 4 | 3 / 3 | 6 / 1 | 干旱30%、丰水20% |
| 缺水村落 | 6 / 10 / 4 | 3 / 3 | 6 / 1 | 干旱60%、丰水10% |

干旱使野食与木材的本季恢复各少1，最低0；恢复不超过场景上限。黏土不会自然恢复。当前天气可见，下一季天气不可预知。场景介绍中沿用的传统技艺叙述不等于当前学科的额外硬门槛。

## 3. 生存、现金与储存

### 食物来源

可以采食、购买口粮、种植小麦/大豆，或把小麦加工为面粉。家庭可食总量为即食粮＋面粉＋小麦＋大豆，各1份抵1粮。季末即食粮不足时，依次用面粉、小麦、大豆补足。

亚麻、种子、秸秆和植物油当前不能当饭吃。施工口粮属于工地库存，不能反过来补家庭生活。

采集通常每行动取得最多2份，实际受当地剩余量限制；切削工具可提高采木量。临时做工每行动得2钱，但默认每季只有1个岗位，因此不能无限劳动刷钱。卖货也受每季4份订单额度限制。

### 食物保护容量不是硬库存上限

基础保护容量4，基础容器提高至8，密闭容器提高至14，家庭粮仓提供30；同类效果取较大值，不全部相加。超过保护容量仍可储存，但季末吃粮后，超出部分每3份向上取整损失1份。

家庭工业材料当前没有通用容量上限；独立作坊和工地才有硬缓冲上限。粮食腐损目前只结算家庭食品，工地已交付口粮不套用同一腐损规则。

### 现金的真正用途

钱支付市场物资、招募、实际工资、教材服务、设备和维护。钱本身不产生工程进度。工程吸收产品但不支付销售收入，玩家需要另外维持现金来源，不能把“产线在运转”等同于“家业有盈余”。

## 4. 学习、实践与知识传播

共有6门学科，每门6阶、共36课题。各学科内部按序学习，彼此没有统一的跨学科学习前置；具体设备和配方会联合要求多门学科。

| 学科 | 六阶课题 |
| --- | --- |
| 力学 | 力与平衡 → 杠杆与转动 → 运动传递 → 功与动力 → 静水压力 → 流动与阻力 |
| 热学 | 温度与受热变化 → 热传递 → 保温与散热 → 物态变化 → 气体膨胀 → 热与功 |
| 化学 | 物质性质与变化 → 溶解与结晶 → 分离与提纯 → 燃烧与氧化还原 → 金属提取 → 酸碱与中和 |
| 材料学 | 材料性质 → 成形与连接 → 密封与耐压 → 耐热与隔热 → 强度与韧性 → 合金与热处理 |
| 农学 | 植物生长条件 → 水土管理 → 土壤肥力 → 栽培与收获 → 选种与繁育 → 病虫害与轮作 |
| 生产组织学 | 劳动分工 → 工序组织 → 成本与契约 → 培训与知识传授 → 协作与管理 → 合作组织 |

第1阶可直接花1行动学习。后续课题通常先取得下一课题的研究/实践证据，或取得教材、家族记录、地区教学来源，再花1行动学习。研究得到的是具体课题证据，不是可任意分配的通用科技点；反复研究已有证据不增加收益。

实际耕作、本人加工、制造设备，以及真实雇佣工作，都能在相关学科形成证据。雇工工作不自动让本人学会其全部专业知识。

四种长期积累要分清：

| 内容 | 作用 |
| --- | --- |
| 本人学科等级 | 决定本人可制造、研究或加工的内容 |
| 后辈学科等级 | 提前教导的结果，换代后成为新经营者能力 |
| 家族记录/教材 | 留下学习来源，通常仍需后辈逐阶学习 |
| 地区传播 | 建立社会教学与商品本地化条件，不直接产物 |

教材永久保留在家庭，但不是买到即学会；付费授课则花钱和1行动直接学会当前下一课题，不附送教材。第2阶有基础授课，高阶授课要求地区已经存在相应教学水平。传播学科通常花1行动和1钱。

当前胜利不要求学满22项或36项。生产组织的部分能力可以读取家族组织记录，其他本人工艺不能用这个例外全部绕过。

## 5. 农业：一块田同时承担生活与工业供料

同一块田由本人和雇工共享，不因雇更多人而增加土地。

| 作物 | 本人播种门槛 | 基础成熟时长 | 基础收成 | 附带秸秆 | 用途 |
| --- | --- | --- | --- | --- | --- |
| 小麦 | 农学1 | 2个生长季 | 6 | 2 | 食品、磨粮、脱粒 |
| 大豆 | 农学2 | 2个生长季 | 4 | 1 | 食品、植物油、提纯溶液 |
| 亚麻 | 农学2 | 3个生长季 | 5 | 1 | 纤维、绳索、密封件 |

基础收成不是实际保底值。实际收成受肥力、设备/人员增益、缺水积水胁迫和延迟收获影响；肥力大于0通常额外贡献1份，收成最低1。成熟后还要执行收获，生长季数不等于完整农业循环的行动数。

循环为：有种子时播种 → 按需照料 → 季末生长 → 成熟后收获 → 留种并安排下一茬。水足时不用强行照料，雇员可等待而不领工资。

收获归还种子，农学5可增加留种；小麦和亚麻收获降低肥力，大豆提高肥力。堆肥可以恢复肥力；农学6还让不同作物轮作产生额外播种收益。农业托管可自动执行小麦、大豆、亚麻或小麦大豆轮作。

这里的长期取舍是：田地种粮可减少生活采购；改种亚麻能供应作坊，却需要从别处解决家庭口粮。种大豆则同时面对食用与工业榨油的竞争。

## 6. 三种生产组织方式

| 方式 | 谁付出劳动 | 物料位置 | 持续性与限制 |
| --- | --- | --- | --- |
| 本人加工 | 本人行动 | 家庭库存 | 灵活；受个人知识、行动与在制项目限制 |
| 家业工匠计划 | 已雇工匠，按工作季领工资 | 家庭库存 | 一项主要配方持续执行，或达到备货目标后停工 |
| 独立作坊网络 | 作坊专属工位，按完成批数领工资 | 各作坊独立缓冲和在途货物 | 当前只有纤维、绳索两类，可长期连接和分别扩建 |

### 本人和家业加工

原料开工时扣除。即时配方当次产出；跨季配方先留下在制品，再由本人花行动完成，或由雇员在后续工作季完成。跨季雇员工序的开工、完工都是实际工作，分别支付工资。暂停不会退料或丢在制品，未完成时不能任意换配方逃避流程。

本人有一个在制项目位置；雇员也各自保留项目，但仍与本人争用家庭的同类设备。当前设备主要按类型记录耐用，不是同类设备可以无限多台并行的工厂系统。

## 7. 雇佣与经营托管

### 四种普通岗位

每类最多雇一人。招募费均为2钱，占1行动和本季招募名额；每季默认只有1个招募名额。普通岗位人数上限随组织能力提高：组织1阶1人、2阶2人、3—4阶3人、5阶起4人。

| 岗位 | 招募组织门槛 | 初始经验 | 工作季初始工资 | 当前职责 |
| --- | --- | --- | --- | --- |
| 普通雇工 | 1 | 0 | 1钱 | 照料、收获，经验8后可播种 |
| 熟练农工 | 2 | 4 | 2钱 | 完整农业循环 |
| 熟练工匠 | 2 | 4 | 2钱 | 专业加工；通过家业生产计划可安排14种配方 |
| 生产负责人 | 5 | 4 | 3钱 | 多种农业/基础加工任务；组织6可附带有限合作交付 |

招到人不会立即工作，必须安排任务。雇佣页的工匠直接任务列表目前只有陶构件、铁料、纤维；想持续制造阀门、传动轴等，要在家业的生产计划中选择。

真实工作每季积累1经验，达到8后工资+1并得到相应岗位效果。本人培训要求组织4，花1行动和1粮、经验+2；商城委托培训花4钱和1行动，次季经验+2，本季停工，不要求本人组织4。

### 家业协议

| 安排 | 条件 | 运行方式 |
| --- | --- | --- |
| 长期供粮 | 组织1 | 预留真实市场口粮，季末按钱和缺口补至4份，不占普通采购运输和个人行动 |
| 农业托管 | 组织2＋熟练农工 | 自动播种、管理、收获、留种；有肥料时改善低肥力 |
| 工匠生产计划 | 组织2＋熟练工匠 | 选择一项配方；备货模式通常每种产物到2份后等待，或持续生产 |
| 自动补货 | 组织2，另行开启 | 为当前农业、生产、作坊与工地计划补料，实际付钱与占采购运力 |
| 自动交付 | 组织2，另行开启 | 按有限订单卖余货，保留基本储备及已安排的作坊/工地需求 |
| 自动维护 | 组织2，另行开启 | 设备耐用≤1且允许维修时送修，本季停机、次季恢复 |
| 家族经营契约 | 组织3，4钱＋1行动 | 经营安排和运行状态跨代自动接续 |

自动补货通常准备2批投入，并计入内部缓冲和在途订单。采购与维护预留已启用人员工资、作坊满负荷工资、已签供粮目标缺口及4钱现金底线。

这些是自动行为的预算约束，不是把钱物锁死：玩家仍可手动花钱、卖料、占设备，因此临近季末的个人行动可能让后续自动计划无法执行。资金不足时，界面会显示等待，系统不会无成本补齐。

## 8. 独立作坊：目前真正具有内部物流的生产链

当前只有纤维、绳索两个节点，不是全部14配方都能自由创建独立工厂。

建立作坊要求组织2；纤维另需本人材料1，绳索需本人材料2。每处投入2木材、2钱与1行动，使用本季招募名额。专属工位不占普通岗位人数上限，也不借用已雇工匠。

- 每个工位每季最多完成1批，每批工资2钱；缺料、缺钱或输出满则等待。
- 原料、成品各有8份缓冲；在途货物预留原料缓冲空间。
- 每条路线默认运2份/季，下一季到达；所有路线先发运已有库存，再加工。
- 每个节点最多2工位。增加工位要再付2木材、2钱、1行动和招募名额，不自动扩大物流。
- 扩运要2木材、4钱、1行动，使该节点相应路线运力从2增到4。
- 家庭手摇、水轮、蒸汽与普通工匠经验目前不加成独立工位；独立工位没有普通雇员的培训/经验系统。

绳索作坊可以从纤维作坊进料，也可以从家庭库存进料。内部连接时，纤维留给下游，不同时运回家庭出售。下游停工会使上游逐步积满，最终停产；终端成品则运回家庭。

当前网络没有自动追溯所有上游配方。缺少密封件不会自动创建榨油、纤维和密封件三条线。普通工匠计划与独立作坊是不同管理方式。

一个实际取舍：纤维→绳索两作坊从2亚麻生产1绳索，需要合计4钱作坊工资；若亚麻按当前本地3钱/份购买，投入达到10钱，而绳索出售是6钱。这个配置可以供应工程，却不能视为自带利润。自产亚麻会改变采购支出，但仍有农业劳动、生活和机会成本。

## 9. 设备、动力与维护

设备有两条取得路径：满足本人知识并支付材料自行制造，或从商城购买可售设备。**购买无需掌握制造学科，但不赠送工艺知识。** 自行制造设备通常花1行动，建成耐用12；购买按现货/订货时间安装。

21项实装设备如下。表内是当前有效能力；目录里有些历史描述仍是旧效果，应以具体行动和运行规则为准。

| 类别 | 设备与当前用途 |
| --- | --- |
| 供水 | 提水辘轳：改善一次田间供水；活塞泵：自动灌溉、矿场排水、试炼施工共用 |
| 动力 | 手摇传动：普通纤维/绳索加工双份；水轮：有水时每季一次食品加工免本人行动 |
| 工具 | 切削工具：提高采木量；锻打工具：轴和阀门加工 |
| 热处理 | 陶窑：陶构件/耐火砖；冶炼炉：铁料；热处理炉：弹簧；蒸馏装置：提纯溶液 |
| 储存与实验 | 基础容器：保护8粮；密闭容器：保护14粮；耐热容器：部分实验节省木材 |
| 农业 | 翻土犁：播种收成增益；播种器：每季一次本人播种免行动；收割工具：抵御部分晚收损失 |
| 农业加工 | 脱粒装置、磨粮装置、堆肥设施：开放对应配方 |
| 农业环境 | 排水设施：抵御丰水胁迫；育苗设施：缩短成熟时间，最低1季 |

当前播种器不再额外增加播种产量；现行行动将它解释为节省行动。设备的展示演进关系也不等于必须先造出全部前代设备，真正的制造要求以学科与材料为准。

普通设备不能用维修刷新出同季重复产出；维修本季不可用，次季恢复12耐用。在制设备不能送修，已被记录为本季使用的加工设备也有限制。维修资金来自家庭，停机可能中断最终合龙。

水轮与蒸汽使用每季共享动力额度，目前并不是有可分配功率、线路与储能的电网。蒸汽是地区供能接入能力，不能当成已实装独立蒸汽机。

## 10. 市场、采购和社会分工

商城支持购物清单：加减清单不花行动，整单结账花1行动；结账时重新校验钱、库存、运输与已拥有设备。默认每季采购运力12，普通商品每种刷新到8份；即食粮使用场景的真实口粮库存。一般物资重量1，设备和家庭资产重量4。

本地现货即时进入家庭，外地订货下一季到达。最后一季不能订无法交付的商品、维修或培训。

当前可以买食物、三种种子、木材、黏土、矿料、亚麻、纤维、植物油、铁料、陶构件、耐火砖、密封件、传动轴、阀门等；**不能直接买绳索、弹簧或提纯溶液**。19种设备可买，热处理炉和蒸馏装置不在设备商城中。

初始基础原料属于本地供应；加工品实际完成至少3批并传播对应配方知识，才可能本地化，降低购买价并缩短交货等待。设备的本地化则要求实际制造与知识传播。买进商品再卖掉不会建立制造记录。

即食粮基础价1钱，其余本地商品通常为售价＋1，外地再加1；面粉在当前商城体系中售价按1钱计算。钱能购买社会分工提供的成果，但市场有品类、库存、到货和运输边界。

### 四种运输不要混在一起

| 运输 | 货物从哪里到哪里 | 限制 |
| --- | --- | --- |
| 市场采购 | 市场→家庭 | 默认12运力/季，现货即时、外地次季 |
| 长期供粮 | 预留口粮→家庭 | 单独协议通道，受市场预留和付款能力限制 |
| 作坊物流 | 家庭→作坊、纤维→绳索、作坊→家庭 | 每路线2份/季，可扩至4；跨季到达 |
| 工地运输 | 家庭→施工现场 | 初始2，完成前两层后逐步增至4；跨季到达 |

几段运力互不通用。市场还有运力，不能说明绳索已经送到工地；家庭有纤维，也不能让内部缓冲为空的绳索作坊立即开工。

## 11. 地区项目：可选的能力路线

家业中的四项地区项目与试炼五层是两套进展。地区项目同时最多进行一项，首次启动默认4钱与1行动，另付材料；暂停后保留投入。默认需3个有效验证季，稳定供粮要求连续，其余累计。

| 项目 | 主要门槛与启动材料 | 验证与成果 |
| --- | --- | --- |
| 稳定供粮 | 家族组织1，已有供粮协议或农业托管 | 连续3季无缺粮且季末至少留下2粮；供粮目标4→6 |
| 地区机械供应 | 家族力学3、材料2，手摇或水轮，2轴＋2陶构件 | 实际动力加工；特定工业自动交付每件加1钱 |
| 深层排水采矿 | 机械供应完成，家族力学5、材料3，活塞泵，2铁料＋1阀门 | 每季1木材、1耐用和1钱矿工分成换2矿料；完成后可持续合作 |
| 蒸汽供能接入 | 采矿完成，家族热学6、材料6、力学4，热处理炉，2砖＋2弹簧＋2密封件 | 每验证季再消耗2木材、1弹簧、1阀门及炉耐用；完成后提供燃料动力 |

试炼没有要求四项目全做，也没有把“深层排水采矿完成”作为施工使用泵的前置。可以直接购买泵用于第四层。实际走哪条路线，应比较学习成本、购买成本、持续原料需求与剩余时间。

正在运行的矿场反而可能占走工地需要的泵，影响合龙。获得更多产业后仍需调度，不能默认全部开启就更好。

## 12. 主线：大运河五层文明试炼

| 层 | 每个有效季的现场消耗 | 同季能力要求 | 默认通层要求 |
| --- | --- | --- | --- |
| 1 施工营地 | 1施工口粮＋1木材 | 家庭无缺粮 | 累计2季 |
| 2 纤维栈道 | 1施工口粮＋1绳索 | 独立绳索作坊实际完成加工 | 累计2季 |
| 3 闸基烧造 | 1施工口粮＋1陶构件＋1耐火砖 | 完成一批陶构件或耐火砖，本人/雇员均可 | 累计2季 |
| 4 排水施工 | 1施工口粮＋1铁料＋1密封件＋1木材 | 现场使用空闲活塞泵，扣1耐用 | 累计2季 |
| 5 大运河合龙 | 1施工口粮＋1阀门＋1轴＋1绳索＋1木材 | 雇员完成一批阀门或轴，且现场泵运行扣1耐用 | 连续3季 |

所有层都要求家庭本季不缺粮。开工花1行动、不收启动钱，同时开启工地供货。每层完成后停止自动施工，下一层由玩家另行开工。

工地仓库16份，包含对在途货物的容量预留；系统根据当前层剩余施工套数发货，尽量均衡装运。第一层与第二层完成各增加1份工地运力，第三、四层开放后续施工，第五层通关。

第一至第四层缺料/缺条件时等待，不倒退累计施工。最终层必须连续3季，失败季将连续计数清零，前面已用的材料不返还。暂停施工、换代后未接续、泵被占用或维修，都可能中断最终层。

### 工程直接预算下限

不发生合龙中断，直接施工共需要11个有效季，消费11施工口粮、7木材、5绳索、2陶构件、2耐火砖、2铁料、2密封件、3阀门、3传动轴，并占用5次泵耐用。

这不包括设备制造/购买、实际加工验证额外使用的原料、所有工资、家庭每季2粮、等待、研究与失败重试的成本。11季是有效施工之和，不是从开局到通关的总时长。

### 真正被强制的能力与可选路线

- 第一层不要求先学科技，可以先用初始木材和余粮建设营地。
- 第二层强制绳索作坊运行，纤维作坊并非硬条件；纤维可从市场购买或手工加工。
- 第三层只要求本季完成陶构件或耐火砖中的一种，另一种物资可提前备好或采购。
- 第四层要泵实际施工，但泵可以购买，不强制本人先学会制造泵或完成采矿项目。
- 第五层要雇员完成轴或阀门中的一种，交付清单仍两种都要；并不要求同一雇员在一季内把两个配方都做完。
- 最后层不要求绳索作坊、窑炉每季同时运行。已有绳索等库存可支撑连续试验。

所以当前支持“部分自产＋社会采购＋提前备货＋关键工序持续运行”的通关组织方式，并没有强制玩家全链自产。

### 交付与运行证据的边界

系统验证两件事：现场消耗了真实物资，本季发生了要求的实际生产/设备使用。它不逐件追溯交付品来自哪一批加工。比如可以把此前手工生产的绳索送到工地，同时让绳索作坊生产另一批满足运行条件。

此前将其解释为“购买绳索送工地”不符合当前商城目录，现修正为上述例子。绳索目前无直接购买入口，但来源未逐件追踪这一边界仍然存在。

作坊成品必须先到家庭，再转运到工地；尚无作坊→工地直达路线。工地泵运行目前由设备可用性、燃料、耐用和占用决定，尚未模拟具体水位与排水流量；施工食品代表建设消耗，也没有单独的工地人口、工时和工资系统。

## 13. 季末顺序决定哪些计划会抢资源

按当前主路径，可分成以下步骤：

1. 自动出售既有余货、按协议补家庭粮，处理维护与自动补货。
2. 农业泵优先灌溉；普通雇员依次工作；作物生长，家庭库存食品按需转为即食粮。
3. 独立作坊先发运旧库存，再加工；普通工匠本季直接产出的家庭物资可供后续环节使用。
4. 从家庭余粮和物资向工地发货，但本季新发货物不能立刻用于施工。
5. 矿场和蒸汽试验运行，再出售新余货、补家庭粮。
6. 家庭吃粮并计算保存损耗，更新地区项目验证。
7. 工地检查本季加工证据与家庭生存，满足条件才消耗现场材料施工；施工泵此时使用。
8. 检查困顿失败、最终胜利、代际交接或进入下一季。

进入下一季时更新天气与供给、恢复行动、交付商城订单/维修/培训，交付作坊与工地货物，清空上季工地加工凭据，再为供粮协议预留市场粮。

几个直接后果：农业与矿场比施工先占泵；矿场本季新产矿料错过了本季工地发运，通常只能后续再运；现场即使有足量材料，缺少当前季生产凭据仍不能过关。界面“上次等待记录”与“当前条件”可能不同，因为新季到货已经解除了上季缺料。

## 14. 传承：保留事业，但不免费复制个人能力

换代后，后辈成为本代经营者，再出现一位新后辈。钱粮、设备、田地、在制品、家族记录、教材、家庭资产、作坊缓冲/物流、工地材料与已完成层数都保留。

本人学科不会整套复制；后辈使用此前教导得到的等级，也可依靠留存来源继续学习。已有设备不因后辈不会制造就消失，已付料的本人在制品可接续。

有家族经营契约，自动经营接续；没有契约时整体经营暂停，后辈需花一次接续行动。该动作恢复保存的农业/工匠计划与整体经营，未纳入计划的普通岗位任务可能仍需单独恢复；独立作坊的单独暂停状态也保留。别把“交接完成”当成“所有雇员都已开工”。

工程累计进度不因换代清空；最终合龙是否中断看有没有实际失去一个有效施工季，不是只看发生过换代。

## 16. 玩家的阶段性任务与当前取舍

开局先判断手里的粮能支撑几季、当地采食能否持续，再决定何时开始第一层。第一层教会玩家把食品和材料送出家庭，为后面的生产扩张建立具体需求。

进入第二层，重点变成组织2、材料2与绳索作坊。可以完整发展亚麻农业和纤维作坊，也可以外购纤维缩短建设过程。前者占用土地和工资，后者增加现金压力；工位扩张、物流扩张与原料供给要分别考虑。

第三层开始需要热加工与跨季项目：保持窑炉有料、有耐用且有人完工，同时保证不同建材的库存。本人补关键批次、工匠负责常态加工，是可行的组织方向，但不是已经证明最优的策略。

后两层重点转向共享设备调度与连续性。应检查泵是否将被农业或矿场占用、维护是否撞上合龙窗口、机械生产是否有足够投入，以及工地库存能否吸收运输等待。盲目扩大生产会提高工资和补货预留，不一定更快通关。

最终准备的不只是3套工程料，还包括3季家庭生活、雇员实际机械加工的原料与工资，以及足够泵/工具耐用。是否提前停矿、暂停其他配方、备货后再开工，成为有意义的决策。

## 17. 已验证与尚未验证

截至本次整理，上一轮收尾有135项测试通过，包括8条旧轨迹、接口保护与试炼专项。默认开局第一层已桌面试玩完成，并验证刷新保留、第二层解锁和工地运力提升。

同一脚本基线、river场景、种子17的第一层小对照：工地运力1需5季、运力2需3季，双方都真实消耗2木材和2施工口粮且无家庭缺粮。报告见 [文明试炼验证](MEGAPROJECT_TRIAL_V13.md)。作坊前版小对照暴露过明显周转压力，见 [作坊验证](WORKSHOP_NETWORK_V12.md)。报告保留各自实际运行时指纹，本次没有重复模拟。

尚未证明：默认开局48季完整通关的可达性、各场景难度、不同产业路线的盈利与公平性、学习/建设/物流投入是否匹配有限时间。测试证明局部规则能按定义执行，不能替代整局体验结论。

尚未实现：多主题副本、战斗、随机奖励、自由地图与传送带布局、全品类独立工厂、电力网络、逐件来源追踪、真正的施工人口/工时、水位流量、疾病传播、教育艺术指标或其他家庭自主产业演化。19项设备仍为规划，不能把目录展示当成已可使用。

当前玩法的完整定位是：**以家庭生存与跨代经营为基础，用有限的生产、物流和社会采购组织，完成逐层验证的实体工程。**
