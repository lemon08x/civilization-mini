# 0.23.0 建设目标完成结算与剩余产能推算

建设是主要游玩过程。每个社会阶段有明确建设目标，完成后即可结算并进入下一社会；不再要求把剩余时间逐季空转生产。

## 建设目标与时间预算

仍是农业村落→集镇分工→工业城镇→现代社会四段。每段保留192季总时间预算（候选可缩短），阶段末12季在目标未完成时提示。退休、交接和交付不能代替建设目标。

|阶段|建设目标|完成条件|
|---|---|---|
|农业村落|家庭水井|建成并完成调试|
|集镇分工|机械供水|建成并完成调试|
|工业城镇|轴加工工位|建成并完成调试|
|现代社会|跨代家业试炼|工程进度达到目标|

目标完成的当季，在本季实际生产入账后结算：把剩余时间按当前有效产能推算，与建设期间实际生产一并兑现，然后进入下一社会。未完成目标的家庭到期同样进入下一阶段，但只结算已经发生的实际生产，剩余时间为零，不再推算。

社会卡、食品到货、服务容量、阶段专用知识、水井与自来水、最终副本路线均沿用0.22；抽卡仍只在阶段开始时进行，未来卡不进入观察。

## 剩余时间怎样推算

推算读取结算当时的已建系统、人员安排和资源约束，不掷未来天气，不推进寿命或消耗口粮。建设期间已经发生的收获和加工仍按原规则计入本阶段凭证。

- 已调试的系统计入有效产能。已安排且未暂停的按当前人员计算；刚建成尚未安排的，剩余时间按本人可承担的劳动推算；主动暂停的不计入。
- 水井、机械供水或现代已付费自来水若可运行，则剩余田间收获按供水保障计算；否则按当地干旱比例折减可预期收成。农业阶段的自来水开关无效，不能把后期服务算进前期。
- 田间按当前作物或可续种的种子连续推算收获次数和肥力变化；没有作物也没有种子则不推算田间。
- 已安排人员的轴加工工位按每季一批、每批2轴推算；假定市场可维持耗材与常规维护。未安排人员则不计入。
- 凭证权重、教育卡九成和阶段管理课+25%与实际生产相同。推算凭证记入同一rewardEscrow，按12份兑1钱向下取整后清零。

本阶段兑现的钱进入家庭并跨阶段保留。后期出现自来水不会抹掉前期水井已经结算的价值；推算也只使用当前阶段可用的服务。

## 验证与结论范围

专项测试覆盖：未完成目标时仍到期结算且不推算；完成水井可提前结算；剩余时间更长则推算收获更多；主动暂停的井目标可完成但田间按气候折减；刚建成未安排人员仍按本人可运行推算；农业阶段打开自来水不能冒充供水保障；轴加工按人员推算；后期自来水不追回已结算的井阶段；观察含建设目标且不含随机状态。
