# 定位与科技正反馈

定位：无地图、回合制、普通人视角的文明发展策略游戏。玩家通过劳动、学习、试验、交换与传承参与历史；家庭生活是行动尺度，技术与社会的发展是长线主轴。

科技的核心奖励是获得以前做不到的行动，并减少维持旧生活所需的劳动。每条主要路线应有可见、可建设、可继承的成果；不能只增加产量数字或立即用新负担抵消收益。

四类反馈：减少旧负担、开放新行动、使已有积累产生新用途、扩大社会影响。不同技术可改善效率、稳定性、保存和教学，不设统一高低文明排名。

首版落实前三类的局部链条：学习与实践 → 掌握手艺 → 建工作台/窑炉 → 批量制作；容器配置 → 本季少损失多少余粮。设施属于家庭，技能属于个人。后人可以接续在制品，但新开批量项目仍需掌握手艺。

社会传承首版（0.4.0）加入家族方法的理论学习减免、邻里传授、作坊委托和公共商品流转。个人能力不会整套继承，但前代事业可由匠人接续；后代换行业后仍可使用容器与收取真实生产货款。使用容器与制造容器拆为不同能力。

个人深入一支知识路线，家族保留方法与资产，社会通过教师、合作与商品连接不同行业。传承是有成本的选择，不能把个人掌握直接变成全世界免费升级。

后续独立问题：当地方法如何跨地域传播，社会积累如何产生新职业、历史阶段，以及其他家庭怎样自主研究。当前全部知识并非由玩家从零发明，本轮不将家庭作坊冒充时代跃迁。

验证标准：同等产品和原料下是否减少制作行动；收益是否被建设、取料和销售挤占；新行动是否在正常初始条件下可达；传承时成果保留但能力不免费复制。参数是假设，小样本不能证明平衡。
