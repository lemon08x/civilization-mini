# 家庭进展与48季节奏 · 规则0.7.0 / 工程0.8.0

仍为每季3行动、16季×3代、初始6粮8钱。采用独立规则household-progress.v7.json，不改旧规则文件。

## 本版改变

- 储存形成补给能力：配置木容器或陶器后，可用buy-food-bulk一次购买4粮，按原单价支付并扣当季市场库存。原buy-food的2粮选项保留；储存不产生粮食，不取消季耗或损耗。
- 熟练劳动减少重复：基础制作完工从1经验改为2经验，经验阶梯系数2→1，等级1/2/3门槛为1/4/9。木作等级1后普通木制品一行动完成；已建木工作台且掌握方法时，一行动可批量完成两件，仍投入两份木材。陶作跨季工序保留。持续制造构件也可升级，不必反复做基础陶器。
- 家学合授：本人掌握且家庭已留存方法时，同一次teach可讲授一次理论并指导一项实践。练习材料与场景条件照扣；不复制前置链。相关工艺每次最多传2经验，累计不能超过父辈现有经验的一半。未留存时教学沿用原流程。后辈可以在交接前掌握，接手后不用强制重练已完成的实践。
- 水利早落地：建设渠道满足原前置、已学一次且有指导来源即可进行；建设真实扣3钱与2行动，并留下渠道模型实践。不必等配水管理全学完。渠道耐用与维护不变。
- 游戏页显示储备可覆盖的生活季数（不含损耗及加工）与上述新能力。节点、配方、动作仍由同一引擎结算。
