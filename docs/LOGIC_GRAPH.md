# 玩家规则总览与科技树

## 当前展示

规则总览 `/review` 按玩家经历组织：开局资源 → 本季谋生与行动 → 学习与实践 → 生产 → 成果用途 → 换季 → 家族传承。每阶段介绍对应子系统，数值从现行规则读取；规则来源折叠放在末尾，实验权限仍在专用栏目。

科技树 `/review#technology` 主图仅显示现行全部17项科技及它们的必要前置、任选前置和有利经验。主图不放熟练度、材料、工序或产品节点，也不把研究候选混入现行科技。

选择科技后，详情依次介绍为什么值得学、怎样学会、在哪里接触、能做什么及其技能门槛/投入/产出、后续科技、跨代保留。工业和高级设备配方复用引擎定义；`logic-graph.ts` 的关系投影用于组织详情，不再作为混合因素主图。详情不是当前人物合法行动判断器。

## 本次纠正

上一版把所有因果关系放进一张图，混淆了科技成长和产品生产。根据用户反馈，取消混合主图、全类型索引及总图/关联链路切换，改为完整科技网络与科技详情。保留原提案为历史记录。

界面调整不改变规则、参数或结算。规则仍为0.6.0，不更换存档键、不迁移旧档、不运行新平衡实验。验证包括科技主图节点与跳转范围检查、完整测试、规则总览到科技树的跳转及节点选择试玩。

产品树现采用领域总览、分支、节点详情三层阅读；现行与规划互斥。科技主图仅默认必要前置，辅助关系按所选科技显示，任选条件在详情中分组。两页提供搜索定位。参见 PRODUCT_TREE.md 的分层阅读更新。
