# 规则预研：要回答的问题

## 预研目标

在正式游戏开发前，用可重复的桌游实验确认：一个时间有限的普通人，在真实资源与机会约束下，为什么会学习、建设、试验和传承；这些决定怎样改变下一代的处境。

初始切片是传统农业；当前扩展为跨地域的食物获取、木作、陶作、储存与有限交换。仍控制一个家庭和成年后辈，不模拟整个人类文明人口；同一知识网络由资源、来源和生产条件形成不同路线。采用规则桌，不引入 Cocos、正式剧情或商业模型 API。

## 五类对象

| 对象 | 自己拥有的状态 | 与其他对象的边界 |
| --- | --- | --- |
| 世界 | 社会已出现的技术、外部天气过程 | 不由个人学习推动；没有全知的玩家观察 |
| 地点 | 雨水、可引水量、教学渠道、交易条件 | 同一技术在不同环境下具有不同价值 |
| 个人 | 已掌握方法、学习次数、实践与领悟 | 知识不是资产；不能凭空生产工具和设施 |
| 家庭 | 食物、钱财、渠道、种源、方法材料、后辈 | 学习、谋生、建设与教学竞争同一份行动资源 |
| 项目 | 试种候选、对照、样本和完成条件 | 有时间跨度和占地成本，可以由下一代接续 |

个人视角允许安排家庭资产与带领后辈，但不能直接控制地区的市场、天气和社会科技。基础生活成本代表整个家庭，不为教学中的后辈额外重复计费。

## 先固定的因果规则

- 社会出现技术、当地能接触、个人学会、家庭持有设施是四个不同事实。
- 任何产出都来自具体过程与投入，节点不会直接发一笔永久收益。
- 学习与实践分别记录；能力前置是知识依赖，不是人物属性阈值。
- 下一代只继承自己学会的能力；材料提供学习渠道，实物提供实践条件，项目保存进行中的工作。
- 操作者只能提交当前合法行动；执行器检查费用、条件、时间与版本。
- 随机外部过程可重放，不让大模型自由编造结算结果。
- 没有统一的胜利分；分别观察基本生活、收入、知识、资产、研究与传承。

这些关系发生改动属于“结构实验”，必须改规则版本，而不是装作普通数值调优。

## 可以调整的参数

学习次数倍率、实践成本、建设成本、设施寿命、维修成本、试种占地、试验持续季数、工资、购买价格、家庭生活开销、观察窗口长度。新生产还可检验采集量、容器保护容量、工具寿命和工艺投入。可用参数和上下限来自冻结规则 JSON 的 `parameterBounds` 与 `production.parameterBounds`；后者通过 `production.参数名` 单独覆盖。

应先写假设再改参数，例如：“渠道设计学习并非主要瓶颈，缺水时可获得的劳动收入过于稳定，技术的替代收益被掩盖。”每次只改变一个机制或一小组紧密相关的参数。

## 推进顺序与阶段门槛

1. **可解释的规则桌。** 每次行动可解释成本、后果及来源；缺钱、缺粮、重复提交、交接、存档重放均有明确行为。当前已经具备。
2. **世界过程校正。** 用少量手动轨迹和脚本对照找出无限外部收入、无代价设施、先验必胜种源等模型问题。当前正在此阶段。
3. **真实 AI 操作。** 不同代理目标在同一观察接口下独立走局，记录模型、提示词、决策理由和不可执行命令。先验证接口与策略，不把模型失误误当规则失败。
4. **有边界的参数实验。** 基线与候选使用相同训练场景／种子；改善后再使用未参与调参的少量留出种子。没有固定必须跑多少千局的要求。
5. **扩展深度与历史。** 当同一节点确实随环境产生不同合理价值，再增加土壤、灌溉方式、育种和后续时代。每次增加的节点都必须找到实际影响的过程。
6. **正式游戏开发。** 规则能够稳定解释生活与传承取舍，手动试玩能理解且愿意继续，才决定正式界面、叙事和内容规模。

## AI 改进循环

观察轨迹 → 找出问题 → 区分模型错误与参数问题 → 写候选假设 → 配对实验 → 检查副作用和留出情况 → 记录接受／拒绝／待研究。

AI 可以自动生成提议与运行已指定的小实验，但不能因“总分提高”自行替换规则基线。只有明确记录采纳原因的版本才成为新基线。不建立无限自我改写和自动发布循环。

## 首版明确没有建模的内容

- 真实的人口年龄、婚育和寿命；八季后是实验交接，不是现实时间中的自然死亡。
- 动态工资、价格、信用和完整贸易网络。0.2.0 已引入有限市场库存、岗位、订单和资源恢复。
- 教师排期、学校容量、识字门槛和家学载体的完整分化。
- 现代遗传育种、材料科学或真实水文学；现有公式是规则实验单位。
- 整个先秦到现代的历史时间轴、迁居与跨世纪跳跃。

这些是待研究事项，不用假装已经通过大量模拟验证。
