# 时间、精力与人生 · 0.17.0

工程与规则0.17.0，基于正式农业0.15版；没有合入独立0.16家学实验的自动知识复制。四季一年，初代40岁、后辈16岁。所有数值都是第一版待平衡假设。

## 每季怎样生活

每季12单位个人可支配时间；精力跨季保留，先天精力8—12。时间表示可安排的工作窗口，不是把一季等分成12个实际工作日。季末常规生活已经抽象处理。

| 事务 | 基础时间 | 基础精力 |
| --- | --- | --- |
| 种植、采集、打工、制造、加工、装运等体力活动 | 4 | 4 |
| 学习、研究、授课、教导后辈 | 4 | 2 |
| 招聘、采购、记录、创建经营安排等 | 2 | 1 |
| 休息 | 4 | 0，恢复5精力 |
| 营养疗养 | 4 | 1，另付2钱恢复8健康 |
| 购物清单、员工任务调整、暂停、设备启停 | 0 | 0 |
| 工具原本免行动的播种或加工 | 1 | 0，材料、能源和耐用仍消耗 |

天赋影响最终报价，以当前行动按钮为准。不能透支时间或精力；精力不足可休息，时间不足可结束本季。休息不能超过精力上限，满精力时不允许刷休息。时间耗尽自动结算；主动结束本季放弃剩余时间。查看状态不推进时间。

季末生产、运输、作物生长和雇佣沿用原有因果顺序。委托工作不再逐项消耗本人的时间精力，但真实工资、投入、设备占用照常。跨季等待不会持续占用个人时间。

## 健康、年龄与家族

饱食季末恢复1健康和基础精力（基础3，按健康比例向下取整、至少1）；缺粮时不恢复精力，每季健康-15。健康影响精力上限：体质乘以 `0.4 + 健康 × 0.006`，向下取整且至少2。55岁后健康上限每年下降2，最低30，疗养不能逆转这个年龄上限。

缺粮困顿仍记录供观察，但本版不再用连续三季困顿直接结束，避免与健康重复惩罚。家庭每季2粮沿用家庭生活包的抽象，不按家谱人数额外征粮；未来人口经济需另立规则。

人物潜在寿命72—88岁，生成后固定、实际死亡还可能由健康归零触发。玩家可以看到年龄、健康、精力与天赋，不能看到寿命阈值、随机状态和未来天气。不含随机疾病、过劳透支和天赋遗传。

后辈18岁成年后可安排季末交接，先完成正常季末结算，再执行交接进入下一季，不能用交接刷新本季时间。人物到30岁且尚无子嗣时迎来一个零岁后辈，只沿经营者与接班人这条家系成长，不扩展完整人口模拟。交接不会凭空创造成年人；年轻经营者暂时没有子嗣时，界面显示尚无后辈。没有存活成年继任者时，经营者死亡会结束本次经营，第一版不含监护代管机制。

资产、家学、田地和未完项目保留；个人理解与实践不复制。退休长辈仍会衰老，但不能反复换回操控来刷新时间。人物系统作用于家族人物；雇员仍是岗位合同，不在本版扩展成员工个体人生。

## 天赋

| 天赋 | 效果 |
| --- | --- |
| 健壮 | 体力活动少耗1精力 |
| 善学 | 学习、研究和授课少用1时间 |
| 善教 | 教导后辈少用1时间、1精力 |
| 善组织 | 采购、招聘、建立经营安排少用1时间 |
| 善恢复 | 休息和饱食季末额外恢复1精力 |

精力体质和寿命潜力独立生成，没有全能天赋。天赋在报价层统一生效，客户端或模型无权自行加成。

## 实现、验证与迁移

统一行动新增 `time`、`energy` 成本，观察新增 `game.life`。旧 `ap` 与旧代长参数仅为兼容历史规则保留，v17不使用它们决定个人预算或换代。天赋生成、身体更新、出生死亡、恢复与交接均由游戏领域结算，行动记录可以严格重放。

规则入口 `rulesets/life-and-time.v17.json`，候选单独保存在 `experiments/life-and-time.v17.json`。假设见 `experiments/life-v17-hypothesis.md`，最小对照入口 `experiments/life-v17-probe.mjs`。机制单测涵盖恢复边界、衰老、出生、死亡、交接和观察保密。实验只能声明实际运行版本和指纹；不将旧报告冒充本版结果。

已完成的验证与结论范围见 [第一版验证报告](../experiments/life-v17-report.md)：165项测试通过；两组种子共4局六季脚本对照严格重放通过；完成短时网页操作检查。

浏览器使用独立键 `civilization-mini.life.v17`；CLI新局使用0.17。旧档与旧规则保留，必须匹配原实现重放，不自动迁移，不修改原档指纹。0.15/0.16人物没有年龄、体质和真实出生轨迹，无法无损推断，因此本次升级方案是新开局。

长寿命下的科技、经济发展速度尚未完成全路线平衡，现版保留原生产内容与速度。默认试玩完成24季只覆盖初期生活与疲劳；要评价传承，应明确执行一次交接并再经营8季；不能把24季当作一生或通关。
