# 被动投资与家族科技胜利（规则0.8.0 / 工程0.9.0）

本版由用户指定方向，先记录假设，再做小样本脚本对照。所有结算仍由 game.ts 的统一 transition 调用；网页、脚本没有直接修改存档状态。

## 玩家规则

| 机制 | 现行行为 |
| --- | --- |
| 校准仪 | 安装时及季末自动尝试：1研究记录+1补给→1校准报告 |
| 提水泵 | 自动消耗1木材，将1公共水转成1蓄水，容量2；缺水耕作消耗蓄水，预览同步 |
| 控温窑 | 自动消耗2用后陶料+1木材→1陶质构件；残料仍来自真实实验 |
| 运行限制 | 每设备每季最多成功一次，每次1耐用度；缺料、水不足或蓄水已满时停机不磨损；自动运行不增加个人经验 |
| 报告订单 | 1行动售出1报告得24钱，占1专业订单；也可留下造泵或窑。做工收入保持原值 |
| 交付并购粮 | 六类工业品均新增此选项：1行动交付1商品，按原售价取得货款，并按市场单价买2粮；扣商品、订单、市场粮，货款不足时补现钱。原交付仍保留 |
| 实习 | 主页面直接显示本人经验、后辈经验、可传授上限和按钮。1行动及既有实习粮耗，每次最多传2经验；总经验不超过父辈一半（向下取整），不代替科技学习 |
| 科技胜利 | 家族所有历代成员实际掌握的科技去重 / 现行17项；目标60%，向上取整为11项。每季末先结算生活，未触发困顿终止且达标即胜利结束。本代或后辈均可贡献，换代不清零。世界已有、购入方法、规划节点不计 |

设备先制造、完成、安装。安装本身仍花1行动；自动功能无需另外点“用”。安装没原料时只是待机，不保证立即产出。设备每季使用标记属于实际运转状态，研究统计不写入游戏状态。交接时实物、余量及后辈自己的经验保留。

科技门槛是待检验设计目标；达到门槛但尚未结算显示待结算，困顿终止优先。48季结束但不足11项只算观察期结束。

## 验证与实际证据

全部是脚本基线，没有调用大模型。默认参数、黏土河谷、种子17；每一对均同场景、种子与策略函数，策略通过观察读取现状并选择当前版本提供的合法行动。每份原始记录含真实规则及实现指纹并严格重放通过。不同专项不相互比较为同策略。

1. [首轮设备路径](../experiments/history/investment-1789123445854/results.json)：4局。外购路线首次校准26→24季、首次泵运行43→41季；窑路线v7第47季装配，v8第48季装配，均未回收。口粮缓冲没有普遍改善。原摘要 `mentorXP` 误统计了所有带 personId 的经验事件，不能作为后辈经验指标；原报告保留，后续脚本已移除此字段。
2. 首轮12钱报告报价因静态成本核算不足而不接受：单报告外购构件5钱及两份补给6钱，还需实验口粮、设备部件摊销。最终报价24钱另存候选，首轮记录不冒充最终报价验证。
3. [工业交换专项](../experiments/history/investment-1789123507632/results.json)：陶质构件路线v7/v8均无生活缺口。季末余粮至少4的季数5→19；工业交付总收入80→104钱；v8同次购入52粮，仍实际付款52钱。实习行动9→5次；省出的行动还用于教学，第二代交接时后辈已掌握木作、控火、陶作。最终仅5/17项科技，不是胜利局。
4. [报告商业专项](../experiments/history/report-commerce-1789123546845/results.json)：同一商业目标脚本，v8第30季完成4份报告销售，收入96钱，设备部件与耗材采购74钱，0缺粮、0手动校准。22钱只是上述收支差额，不含生活、行动机会成本，也不是全局纯利润。v7跑至48季只得2报告、采购63钱、缺粮2，无报告销售接口；两者停止条件为目标完成或观察期终止，并非同长度利润排名。

完整 npm test：78项通过，包含8条旧轨迹与接口保护。其后发现交付购粮未计入经历账单，修正研究展示汇总，相关13项测试通过。该修正不改变物理结算或实验条件，未重跑实验。单元夹具覆盖自动触发、同季防重、缺料/满仓、资源守恒、经验上限、科技胜利及困顿优先；夹具不能证明默认路线可达性。

短时桌面试玩：新版0.8.0页面显示0/17、目标11项、实习入口；购买构件后从新增面板交付购粮，钱3→5、粮6→8、市场粮6→4，行动2→1；反馈显示货款及购粮支出。

## 决定与尚未平衡的部分

采纳自动设备、24钱报告订单、工业交付购粮、加强实习与科技胜利。没有通过削弱做工制造生存惩罚。

窑的建造链仍很晚，本版只保证安装后不再多花使用行动，不能宣称所有高级设备均在48季内回本。60%科技胜利已有真实终局逻辑及边界测试，但尚未完成专门的默认开局胜利路线试验，不保证单一工业路线能获胜。泵节粮需真实缺水耕作，窑节料需足够实验残料，均非无条件收益。
