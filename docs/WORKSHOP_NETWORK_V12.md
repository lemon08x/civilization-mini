# 作坊协作 · 规则0.12.0 / 工程0.13.0

在0.11.0长期经营上增加一条可选的亚麻—纤维—绳索经营路线。保留无地图、每季3行动、季末结算、生活需求与家族传承。没有新增电网、空间铺设或全品类自动工厂。

## 操作与因果

在「作坊」页建立纤维、绳索作坊。生产组织2阶或家族记录是组织门槛；本人材料1阶可以建立纤维作坊，材料2阶可以建立绳索作坊。每处花2木材、现有招募费和1行动，占1当季招募名额，获得一个独立工位。它不是现有熟练工匠的免费复制，也不占用他的个人生产计划。作坊工位代表长期雇用的专门人员。

- 配方沿用原目录：2亚麻茎→2纤维，2纤维→1绳索。每工位每季最多一批，实际完成一批付基础工资+1钱（当前2钱）。无原料、无输出位置或无工资时不扣料、不收工资。
- 两作坊分别有原料和成品缓冲，默认各8份。内部货物不属于家庭可用库存，不能直接出售或拿去手工制作。
- 所有路线先发运已有库存，再生产；发出后下一季到达。新产品最早下季发运、再下一季到家。运输预留目标缓冲空间并计入在途货物，不能超装或复制货物。
- 纤维作坊从家庭取亚麻。绳索可接纤维作坊，也可从家庭取纤维；家庭原料既可自产，也可购买。先建纤维再建绳索时默认连接。切换仅影响后续发运，已发原料照常到达。
- 连接下游后，纤维全部留给下游；下游暂停会使上游逐渐积满并停工。解除连接后，纤维重新运回家庭。终端产物运回家庭才可消费或出售。
- 每个工位扩建需另付2木材、招募费和1行动，最多2工位；运输和缓冲不随工位自动增加。运输扩充需2木材、项目组织费和1行动，每条路线从2份/季增至4份/季。纤维→绳索使用绳索作坊进料运力。
- 暂停/恢复不花行动，但不产生结算；暂停停止取新料和加工，已有终端成品仍可外运。在途货物不撤回。家族整体暂停时不再发新货、生产，旧货仍到达。
- 现有家庭手摇设备、工匠经验及动力额度不加成独立作坊；本轮只模拟人工作坊，不假装已经实现共享动力网络。

主入口仍是 `src/game/game.ts`；网页、CLI、脚本经同一行动接口。新增行动为 `economy:workshopbuild:fiber|rope`、`workshoppause`、`workshopexpand`、`workshoptransport`，以及绳索的 `workshophousehold` / `workshopupstream`。非法或条件不满足的行动由统一接口拒绝。

## 与现有家业的关系

农业收获进入家庭库存后可供应作坊。已有补货协议按作坊来源补足两批原料，扣除内部缓冲和在途货物；内部纤维路线不采购纤维。市场订货在途与作坊运输在途分别保留，进口不会跳过作坊装运时间。

补货及维护预留全部已启用作坊的满负荷工资、既有雇员工资、供粮缺口和原有现金底线。自动销售保留家庭供货路线需要的原料，绳索仍按既有规则保留2份后售余货。产出、工资与发运由事件报告，不往 GameState 写累计统计。界面区分当前开工条件和最近实际运行记录。

现有雇员先工作，作坊随后按纤维、绳索顺序使用剩余现金；有限现金下可能使后续工序等待。满负荷工资预留约束自动采购，不能保证其他个人支出后仍有足够现金。

作坊配置、工位、缓冲和运输跨代保存。无家族契约时，随整体经营暂停，一次「接续家族经营安排」恢复；有契约则持续运行。已单独暂停的工序保持暂停。个人学科不复制。胜利条件仍为知识与地区成果，作坊不是额外必做任务。

## 验证与接受范围

研究假设先记录于 `experiments/workshop-v12-hypothesis.md`。规则候选保存在 `experiments/workshop-network.v12.json`；新建 `rulesets/workshop-network.v12.json` 作为0.12.0入口，没有覆盖任何历史规则。

专项测试覆盖建设成本与门槛、链条延迟与物料守恒、堵塞及恢复、有效工资、扩建与运力、替代来源、缓冲上限、采购保护、代际接续、参数边界、旧版隔离与严格重放。供应与现金充足的10季专项场景确认提高运力会增加实际产出；不是默认开局收益测试。

收尾统一执行一次 `npm test`：126项全部通过，含9项作坊测试、8条旧轨迹与接口保护。短时桌面试玩在独立4318端口从新局完成「劳动分工→雇佣→工序组织→材料性质→建立纤维作坊」，确认实际扣2木材和2钱、正确显示缺亚麻；暂停后季末现金保持4钱，恢复并刷新后配置严格重放保留。检查了页面布局；整链运输与产出由专项测试及下述脚本记录验证，未把这次界面试玩写成全链盈利验证。

## 版本与存档方案

新增字段仅在0.12.0启用；0.11.0及更早版本的初始状态和行动不加入作坊。旧版轨迹测试与冻结基准照常保留，不能用旧档伪装新版对照。

浏览器新版使用独立键 `civilization-mini.workshops.v12`，原 `civilization-mini.enterprise.current` 及其他键不读取覆盖、不删除。新版从新局开始；导入仍严格要求当前规则和原始实现指纹，读取失败不自动保存。CLI原记录和报告不修改。

本轮迁移策略是**隔离保留原档，禁止自动迁移，另开新版**。若以后需要迁移，必须另立转换规范：使用匹配原始指纹的原构建重放旧记录，再明确映射新状态和新来源清单；新规则字段不能简单补入旧轨迹。本轮不制作兼容指纹，不提供未经校验的转换。

作坊参数仅 `workshops.buffer`（4—16）与 `workshops.transport`（1—4），都按整数边界校验。参数实验写独立候选，不自动覆盖入口。
