# 当前科技与生产成长路径 · 0.17

本文件依据当前领域目录、学习规则、商城与副本条件梳理，不是建议方案，不代表已跑通的最短路线。不含0.16候选传动工场。仅文档整理，未运行测试或模拟。

## 怎样读这棵树

- 六科学习各自逐阶推进；课题之间没有跨学科硬前置。跨学科要求发生在设备、生产和项目处。
- 首阶可直接学；之后需要对应证据、教材、家族记录或地区来源。得到高阶教材不等于跳过低阶。
- 自制设备检查知识与原料；实际加工还检查配方知识、设备、材料和能源。买设备不自动获得加工知识。
- 设备目录的 from 是效果/发展关系，不是必须先造前一设备的硬前置。
- 下述自制链可在商城允许时通过外购替代；供应等级、钱、库存和运输仍限制外购。

## 用途与隐藏前置

1. 开局仅本人和后辈农1。小麦提供生活；农2增加大豆/亚麻，分别进入油料和纤维链。材1的容器可扩大储存；力1的辘轳改善田间供水。但翻土犁、切削工具虽是一阶设备，仍需要铁。
2. 热1＋材1建窑，材2才会烧陶。陶器可用于力2磨粮装置（2麦→3面粉），也能交窑场取得启动铁料。
3. 材2锻打工具需要铁2，再用力3和铁1制造轴2，恰好耗尽窑场奖励的铁3。手摇传动名义力2，但自制轴要力3；水轮力3还需额外铁。可购买轴或设备来替代，需供应与资金。
4. 水利要求轴、密封与绳。自产密封需要亚麻→纤维、大豆→油；仅一块田，因此作物轮换与口粮共用土地。外购原料能缓解。活塞泵需要力5，但水利副本并不要求建泵。
5. 水利后开始电气化自制链：供应6提供铜/化工原料 → 热7＋化8的反应设备 → 化8聚合物 → 材7绝缘铜线 → 力8线圈、材8电缆 → 水力发电 → 输电验证。输电面板的力8/材8掩盖了完整自制时的热7/化8要求。
6. 电池名义化7，但自制所需反应设备要求化8/热7；电动离心泵名义力7/材7，但自制线圈要求力8。外购可改变实际门槛。
7. 输电后的电子制造需要洁净台（化9/材9）及电力；电路需力9/材9。后期要求雇员、无线调度共同运行。制成品与设备还可能依赖供应8以上的外购。
8. 最后复合设备需要控制器，协同控制中心需要复合件；部分启动材料由电子副本奖励提供。知识学满不等于供能、加工和运输能连续运行。

## 当前可见的过渡疑点（待体验验证）

- 知识可以先于生产快速上升：2—6阶很多实验只消耗木/黏土/种子，不要求先建对应工业。理论等级与实际生活改善不必同步。
- 窑场→水利在较短目标跨度里同时要求金属加工、油料和纤维链，但泵和持续排水尚未成为必须体验的内容。
- 力学/材料3→8的副本目标跨度很大；已有的矿场、蒸汽、机械经营没有被串进主副本成长反馈。
- 供应等级1→2→4→6→8→10将多种材料与设备成批开放，可能比逐项工艺成长更决定推进速度。
- 9—10阶自行研究统一需要电路，包括农学、组织学；这是跨全学科的样本门槛，教材和记录可替代，并不意味着所有人都必须先自制电路。
- 自动化组织2很早开放，但现代加工对雇员重新检查本人的高阶知识，个人与组织能力的责任边界在6→7阶发生改变。
