## 一、为什么电力必须成为关键节点：历史教训

### 1.1 项目内历史：电力曾正确，后被阉割

| 版本 | 电力的地位 | 结局 |
| --- | --- | --- |
| v13 两河大运河 | 无电，纯材料工程 | 副本原型 |
| v14 现代电网 | **电力是主线关键节点**：五层工程每层要求真实耗电，最终层最低 7 电/季；发电/储能/服务/工地共用电力池；水电机组、燃料机组、光伏、储能柜、无线电、数字控制、冷库、温室、传感站齐备 | 平衡未验证，48 季通关未证明 |
| v15-v26 | 重构为时代化，**电力系统被大幅削减**：只剩 E01 水力发电机组（6电/次）、L4-L7/M4/M5 节点、battery/circuit/controller/composite 等无生产配方的商品壳 | 三局试玩**电气线零接触**：副本无电力路径、结算不要求电、商品壳无消费端 |

**根因**：v14 的电力系统是完整闭环，但依赖"五层主线"这一整体框架；时代化重构把主线拆散后，电力闭环没有随迁，只留下了零散设备与商品名。**这不是电力设计失败，而是系统背景没有承接它**——v27 的任务不是加回设备，而是重建"电力 = 现代生产组织方式"这一背景。

### 1.2 人类电气化史：电力成为关键节点的五个重构

电力之所以在真实历史上**不可绕过**，不是因为"电比蒸汽省一点"，而是它重构了五个维度：

| 历史事件 | 重构的维度 | 对游戏的设计启示 |
| --- | --- | --- |
| 1882 珍珠街中央电站 | **能量可以离开产地**（集中发电 + 输配） | 电网是"基础设施"，不是"一件设备" |
| 1890s 交流电远距离输电 | **打破就地取能**（能源与生产地分离） | 输电/并网成为现代阶段的组织形态 |
| 1913 高地公园流水线 | **生产组织重构**（电动机替代天轴传动，车间按流程重排） | 电 = 生产组织变革，不是单机加速 |
| 1886 霍尔-埃鲁电解铝 | **材料革命**（铝从贵金属变廉价） | 电开启新材料层级 → 新产品树 |
| 电灯/电报/电话 | **时间与信息结构变革**（夜班、即时通信） | 电器改写时间上限、物流时滞、信息规则 |

**结论**：让电力成为关键节点的正确方式，是让**现代阶段的一切高价值活动（结算、副本、高级商品、信息、时间）都以电网为输入**——就像历史中"电气化"与前电气化是两个时代，游戏里"有电网的现代"与"无电网的现代"必须是两种世界。

## 二、系统背景重构：让电力成为历史必然

### 2.1 四阶段的"生产组织"演进（新增背景叙事层）

| 阶段 | 生产组织形态 | 动力来源 | 限制 |
| --- | --- | --- | --- |
| 农业村落 | 人力 + 畜力 | 人 | 时间上限 12，旱季减产 |
| 集镇分工 | 水力/风力就地使用 | 公共水利（公井） | 动力不可移动，依赖当地 |
| 工业城镇 | 集中动力（水轮/机械传动） | 机械动力 | 动力在"工位"上，无法分配；公共磨坊兜底加工 |
| **现代社会** | **电网 + 电器 + 电动生产线** | **电** | **无电网 = 现代生产停滞** |

背景叙事（用于界面与文案，不改变结算之外的规则）：前三阶段的动力都"拴在某个地方"，只有电能把能量**从产地送到需要它的任何地方、再按需分配到任意设备**。这是历史给我们的答案：电气化不是技术的第四步，而是**组织方式的断层**——跨过它，生产/生活/信息/时间结构全部改变；跨不过去，就停在工业城镇。

### 2.2 关键节点性设计（不可绕过的三条锁链）

1. **现代阶段目标 = 建成家庭电网**（替代 v26 的"任意结算"）：现代阶段必须"发电 → 输电 → 接入电器 → 维持用电负荷"持续 N 季才算电气化完成；未完成则现代结算按"前电气化"产能打折。
2. **现代高级生产 = 电为输入**：线圈/电路/控制器/复合材料等现代商品配方全部要求"通电工位"（像 v14 的电子制造台 2 电）；电解铝、电镀等新配方同样要求通电。**没有电，现代商品一个都造不出来。**
3. **最终副本 = 电气化验收**：副本推进新增"供电/交付电器"路径，且副本完成条件包含"家庭电网连续在线"；电成为胜负的物理前提，而非可选加分。

### 2.3 社会服务与电力的关系（承接历史，而非对抗）

v26 的公井/磨坊是"社会代劳科技"——这是历史正确的一步（公共设施先行），但到现代必须让位给电网：
- 集镇公井 → 现代改为**市政自来水**（保留，付费）：这是"公共服务"的延续，不取代电网
- 工业公共磨坊 → 现代保留但**效率上限固定**（2麦→1面粉）：私人电动磨坊（2麦→3面粉）成为电网的收益点——**公共服务是保底，电网是上限**
- **新增背景规则**：现代阶段"社会代劳"类服务（配送、自来水、磨坊）每季消耗**地区电网配额**——社会能代劳的前提是社会有电。玩家不建电网则社会服务容量减半（历史对应：先电气化的城市才有夜班、有轨电车、自来水加压）。

## 三、完整系统设计

### 3.1 电网系统（新增状态与每季结算）

```
电网状态 = { 发电量（本季已发/上限）, 输配（线路数）, 储能（电池容量/存量）,
             负荷（接入电器清单）, 停电记录 }
```

- **发电**：E01 水电机组（6电/次）、新增燃料机组（1精炼燃料→6电）、新增光伏阵列（丰水 2电/其他 4电，随天气，不泄露未来）
- **输配**：L7 配电解锁"接入第 1 个电器"；每多 1 条输电线路（需电缆）可多接 1 个电器——**线路数 = 电器容量**，这是资源约束
- **储能**：蓄电池（电池×2）提供跨季存储，改写"电不过季"规则；电池容量限制
- **负荷与停电**：每季结算按"停机顺序"扣电；电不足则电器停摆（显示"停电"），玩家可选择保留手动退路（用手干，回到前电气化效率）——**这是风险管理决策，不是随机惩罚**（旱季发电减半，可预期）

### 3.2 电器层（每个电器改写一条规则）

| 电器 | 制造（复用已有商品） | 独特效果（规则级） | 耗电/季 |
| --- | --- | --- | --- |
| 电灯 | 铜线×2+玻璃 | 每季时间上限 12→16；解锁"夜间学习"（超时仍可学） | 1 |
| 电报 | 电缆+电池 | 订货当季交付；解锁市场情报（下季价格预告） | 1 |
| 电动机 | 线圈+铁 | 指定一台设备本季自动运行（不占本人时间精力，处理2批） | 2 |
| 电解槽 | 铜线+陶构件+铁 | 开启电解：黏土/铝土+电→铝 | 3 |
| 温室 | 玻璃+铁+木 | 冬季可播种；旱季保湿 | 2 |
| 冷库 | 陶构件+密封件+电 | 食品保护容量至少 30（替代容器数值） | 1 |
| 蓄电池 | 电池×2 | 电可跨季储存（创造电力储备） | 0 |

### 3.3 材料革命：电解铝 → 新材料层 → 新产品

```
电解槽 + 电 + 黏土/铝土 → 铝（新商品）
铝 → 铝线（替代铜线的材料决策）、铝犁（不损耗耐用）、铝容器（零损耗、容量+20）、
      铝制现代产品部件（电路/控制器/复合结构件配方中可选铜或铝）
```

**材料替换决策**：铜线"贵而稳"（需 channel:metal 稳定供货）vs 铝线"便宜但每季绑电"（无电则效率-50%）——把材料线、电力线、供应链三线交叉成网。铝的收益**依赖电网**，因此"造铝"直接激励"建电网"，形成自洽闭环。

### 3.4 科技树改造（电气线从可选变主线）

- **前置收紧**：L7 基础配电不再只做"接入本地加工负载"，而是"接入家庭电网"——L6（发电）→ L7（配电）成为**现代阶段结算/副本的前置主线**
- **unlockEra 调整**：L4/L5/M4/M5 保持工业开放，但新增收益挂接（组合协同）：L4+L6+M5 解锁"水电联动"；L5+M4 解锁"电磁应用"
- **收益维度**：O3/O4/O5 的 +25% 凭证保留，但电气线不再给百分比——电气线的收益是**规则改写权**（时间上限、即时物流、冬季播种、自动化、材料革命），与数值加成形成两种不同的"值"

### 3.5 副本联动

- 新增 `dungeonwork:power`（本季发电 ≥ 4 电 → 进度 +2）：电力直通胜负
- 新增 `dungeonwork:appliance`（交付 1 台电器 → 进度 +3）
- 副本完成条件增加"家庭电网在线"（若 v27 需要收紧节奏，可只在最终验收季检查）

## 六、一句话总结

v27 不是"给现代加电"，而是**让现代之所以是现代，是因为有电**：电网是现代阶段结算、高级生产、最终副本的物理前提；电器改写时间/物流/季节/材料规则；电解开启新材料层；社会服务降级为"保底"。电力从"可选分支"恢复为**历史中它本来的位置——现代工业不可绕过的地基**。彩蛋文案让每项科技与操作都带着一句"这个家族世代相传的认知"进入玩家视野。
