# 双玩家入口

- `/`：选择入口。
- `/start`：独立开始界面，选择环境、世界编号，开始新生活或继续已有进度；开新局前原样备份旧存档。
- `/play`：人类聚落界面。资源栏、家人健康精力、田地生长与肥力、仓库卡、地点导航、学科进度、产品验证和系统阶段；行动按钮显示实际报价，禁用原因可见，详细规则按需展开。
- `/ai`：AI 接入说明；`/ai-guide.md` 为纯文本指南。
- CLI 新建、导入、行动成功后生成 UTF-8 `observation.md`；只由公开观察生成。`--format text` 可直接输出文本，默认 JSON 兼容保留。观察副本不是结算权威。

只涉及应用与呈现层。保留 0.20.0 规则、严格重放与原有浏览器存储键；不迁移历史存档、不刷新历史报告。浏览器和 CLI 分别存档。

## 分类与规则详情

主导航分为本季总览、生活与家人、学习与制造、经营与交易。家人和仓库为独立功能页，首页不再展开田地与家人操作。雇佣与人员配置统一从生产系统进入。

每个功能标题旁提供规则详情入口，可返回原功能。学堂按当前可学、待前置、已掌握分类；课程展开显示用途、前置和实际行动费用。详情与分类均不提交游戏行动。
