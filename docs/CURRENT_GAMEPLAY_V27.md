# 0.27.0 电气生产与通电验收

本文件是现行 0.27.0 的实际规则：文明阶段、社会服务、自选结算，以及可操作的电气链。

## 时代与代际

四个时代按代际计时，不再固定季数。农业村落、集镇分工、工业城镇各最多住 5 代：进入第 5 代时提示"最后一代"；第 5 代交接时本时代强制结算，只兑实际生产、不推算剩余，下一时代由无亲属关系的新随机人物开始。主动结算仍按代际估计推算剩余时间兑现：估计代长为 26 年（约 104 季），当前代剩余按后辈已活季数折算。现代社会不限代、无超时、无提醒。

## 家人与成长

人物出生时随机确定性别、外貌和一个天赋（健壮、善学、善教、善组织、善恢复）。性别不影响能力，所有人均可参与全部活动，没有职业限制。同一时代内，姓名、形象与出生天赋在成年、接班和退休时保留。同一性别优先分配本局未用的肖像，图库耗尽后复用；肖像不决定天赋。

18 岁成年，26 岁且尚无子嗣时生育，55 岁开始衰老。饱食与陪伴记录在成年时增加体质；教导帮助后辈学习，不再替换天赋。肖像按 0–5、6–11、12–17、18–34、35–54、55 岁以上六阶段变化，仅用于呈现。肖像同时区分农业村落、集镇分工、工业城镇、现代社会：每个时代启用独立家族，跨时代不把原人物换装延续。主动结算或最后一代交接进入新时代时，生成一名 18 岁、无亲属关系的新随机人物，性别、姓名、肖像、体质和天赋重新生成，个人课程从初始基础 A0 开始；初始没有后辈，满生育年龄后在本时代建立后代。旧时代人物和知识留作历史记录，不再参与季末成长、死亡、请教或直系传承优惠。新时代代际预算从第一代重新计数，不继承待交接、陪伴或请教状态。时代差异不增加能力或职业限制。寿命不进入观察。同一时代内交接保留后辈身份与已有知识；跨时代保留钱粮、资产、生产规程和公共记录，不把旧人物知识复制给新人。亲自操作的机器暂停，由新人安排；其他资源与阶段回报按现行规则结算。现代最终结算结束旅程，不再生成新人。

## 供电与消费

工业社会开放 L5/L6、M4/M5，现代开放 L7。知识之外仍需实物、前置产品验证和原料；外购设备不赠送制造规程。新产品和配方在制造页、商城与玩家观察中使用同一目录。

| 设备 / 工序 | 实际投入与结果 |
| --- | --- |
| E01 水电 | 启用后手动调度，每季最多一次，消耗1公共水、1耐用；旱季3电，其余季6电 |
| E02 燃料发电 | 每季最多一次，消耗1精炼燃料、1耐用，产生6电；不耗公共水 |
| E04 储能柜 | 启用后季末储存最多6份余电，每次充电扣1耐用；手动调度时每季最多放电一次 |
| 电灯 | 启用后供能，首次点亮耗1电、1耐用，当季增加2可用时间；仍扣学习或劳动精力 |
| 电报终端 | 启用后供能，每季耗1电、1耐用；此后当季新订货即时交付，仍扣价款、库存、运输 |
| 电解槽 | 无启停开关，按批加工；2氧化铝原料＋3电＋1耐用 → 2铝 |
| 铝导线工艺 | 1铝＋1绝缘聚合物 → 2份绝缘导线，进入已有线圈、电缆等配方 |
| F07 化工设备 | 制造后支持原有精炼燃料和电池工序，补齐燃料发电、储能柜的自制路径 |

操作顺序：安装设备 → 启用需要的发电机、储能、照明或电报 → 执行本季供能 → 按需加工或向副本供电。调度固定耗2时间、1精力，先水电、后燃料、再储能放电，负载按照明、电报顺序结算。可先停用非必要负载，把电留给加工与工程。缺料、缺水、设备维修或缺电均停机，不凭空产生能力。

电灯把基础12时间的当季预算提高到14，但调度本身仍花时间；与同时安排的其他用电任务共同衡量收益。关闭再开启不会刷新当季额度。所谓夜间学习使用这2份额外时间，不存在无限透支或零精力学习。

电报只协调新订货，不加速既有订单、维修或培训，不突破运输容量，不预知随机天气或未来行情。铝不是从黏土直接得到；需购买氧化铝原料并实际电解。铝导线进入统一导线库存，代表配方替代，不模拟电阻、电压和线路损耗，也不要求制成的铝导线持续耗电。

季末不自动发电、不开启新的电器服务；余电可入储能，未储存的电跨季耗散。旱季产能可从当前天气及供能页直接看到，不读取未来天气。

## 现代结算与副本

现代阶段结算时，本季真实运行过电灯、电报或电解槽才取得100%回报；只有设备、启用开关或单纯发电不满足条件。未满足时，总回报凭证（含主动结算的剩余产能推算）先按85%向下取整，再按原兑换比例兑现。结算预览采用相同口径，前三阶段不受影响。公共食品、自来水、磨坊保留原有保底服务。

副本改为六个一次性任务的任务板，每项任务只能完成一次，按分值计分，满分10分：

| 任务 | 条件 | 分值 |
| --- | --- | --- |
| 家庭余粮 | 交付4份家庭余粮 | 1 |
| 传动轴 | 交付2根传动轴 | 2 |
| 委托施工 | 支付10钱委托施工 | 1 |
| 数学验算 | 完成一轮数学方案验算 | 1 |
| 通电验收 | 交付4份可用电：需掌握L7，真实扣电；储能放电同样是可交付的真实电能 | 2 |
| 可用电器 | 交付一台本季未使用的可用电器：实物移出家庭并停用，按电灯、电报、电解槽顺序选取；制造规程保留，已运行的设备当季不能再次作为交付实物 | 3 |

旅程胜利＝通电验收完成且总分≥6，之后主动结算现代结束旅程；超出6分记为高分。不能仅靠交付粮食或买设备获胜。任务不可重复完成，完成后的重复交付被拒绝。未完成也可结算结束旅程并保留阶段回报，但不算胜利。本版不要求连续多季在线。

## 参数、版本与存档

参数在 `rulesets/v27/`：时代参数键为 generationLimit（代限）、rewardDivisor（回报折算）、dungeonTarget（副本目标分）；life 的 birthYears 为 26，即代长约 26 年。电气等子系统数字在 `systems.json`，物价、产量和配方投入在 `catalogs.json`。支持 `resolveRuleset` 的有界覆盖。名称与结构仍在 TypeScript 目录。

网页和 CLI 只加载 0.27.0。网页从开始界面打开存档或新开，不自动进入上一局。旧存档不覆盖、不迁移。读档失败时保留原文件。

电气节点的观察与行动说明不参与物理结算或随机抽取。

## 验证与未包含范围

机制用例在 `tests/`，只在明确要求时运行。不跑千局实验，不把试玩感受自动写成规则。

[开发冒烟试玩](../playtests/batches/pt-20260916-v27-smoke/feedback.md)完成1局短程入口检查和现代无电结算；浏览器检查了供能面板。它不是长期经营、通关难度或收益平衡证明。

光伏、数字控制、冷库等其余现代设备仍属于历史 v14 实现，未全部接入本版三类树。连续在线电网验收、地区电网配额、未来行情、玻璃产业、铝犁及更多电器仍是后续候选；不提供永不磨损的工具，也不靠仅展示目录宣称已实现。
