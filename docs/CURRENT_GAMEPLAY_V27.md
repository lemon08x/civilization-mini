# 0.27.0 师徒传承、道术修行与现代使命

现行规则以修道习术为成长主线，以现代存续危机为唯一计分来源。门派奉行兼爱、非攻，隐世积累，只有人类存续受到威胁时整体出手。

## 师徒与时代

每位开局传人及寻访候选独立随机生成性别、姓名、肖像样式、行事风格、天赋、职业出身、时代身世、情感牵挂与心愿。姓名不按血缘统一姓氏；所有性别均可获得任一天赋和职业。职业是社会身份，未成年显示职业见习，不赠送课程、设备或额外职业加成；角色能力仍取决于实际天赋、道与术。行事风格以人物文案呈现，肖像沿用现有分性别、分年龄素材。

招募时可查看完整人物资料，生成后保存，不因观察、读档或正式收徒重抽。入门、成年、首次学习新术、初次破境、收徒授业、心法改进、中年、退休与年长等真实经历逐项写入生平，并改变当前心绪；同一里程碑只记录一次。各人原有身世与牵挂保持连续，时代变化只更新当前职业与适应经历，不改写出生背景。成长记录与人物身份跨代保存，已故人物留在谱系中。里程碑情感叙事不直接改变数值；季末事件会按实际行动与处境结算资源、关系与性格，不新增婚恋或婚育机制。

开局两人20岁，你固定控制第一位，另一位是独立同门，不可切换。自己可以寻访一名16岁候选并正式收徒；候选不在生活模拟中老化，入门后逐季成长。婚育不决定席位。

18岁成年；自己的弟子成年且在世后即可交接，不依赖同门。交接保留弟子实际所学、心法、卡牌、气运、资产、地块及规程，不复制师父修为或个人知识。退休师父在世时仍可请教；本人去世后只允许成年弟子接续，不切换到同门。

本人时间与精力用于自己的行动；同门有独立劳动预算、田地与库存，季末自主照料和轮种豆、麻，不占用玩家的种子和收获。同门会衰老离世，本版不生成替代同门。耗尽时间不会自动推进季度。

开局选择社会发展框架；当前完整实现「大河农耕」，爱琴海城邦、安第斯文明、尼罗河文明仅为未开放预告。科技按四阶段主线组织，已学知识跨阶段保留，旧阶段可继续研习：

- 农耕村落：种田、探索与储粮；开放 A0—A4、M0、M3、L0。栽培分向水分、井渠、肥力和豆麻；材料识别分向储粮，受力基础用于简单提水。
- 市镇百工：工具与农产加工；开放 M1、M2、L1—L4、O1、O3、Q0—Q2。生产工序 O1 改以成形与连接 M1 为前置；集镇生产核算 O3 前置为 Q2、M1，不依赖工业用工。机械供水系统需要 A1、L3 与泵的实物验证，不再依赖劳动分工 O0。
- 电力工业：购置设备、组织生产与市场经营；开放 M4、M5、L5—L7、O0、O2、O4、O5。基础配电 L7 前置为电磁转换 L5、绝缘 M4，不必先学发电机制造 L6。绕组与发电机归设备制造专业支线。采购交付 O2 前置为 O0、Q2；生产调度核算 O5 归工业。
- 现代社会：资本玩法筹备中，暂不新增无实际效果的金融科技；既有知识继续有效，保留现行存续使命。

公井与公共磨坊仍在市镇开放；工业提供公共铁料、电工材料市场；现代提供市政口粮与付费自来水。科技树编排不改变这些公共服务。

基础雇佣从电力工业开放，不要求先学习 O0/O1；基础人数上限、招募机会、招募费、岗位资格与实际工资继续检查。O0 用于配送和岗位安排，O2 用于进一步经营安排。手动买卖不增加科技门槛。工业阶段可直接购买发电机，电气设备外购检验检查 M4/L7 与实物、耐用和试运行资源，不要求制造部件链；供能与电力服务实际运行改检查用电基础 L7。自行制造继续检查绕组、发电机知识及部件验证，不因购买取得规程。旧档已雇人员与已学知识保留，不迁移状态。

A4 的直接学习改为实践试种：先通过探索辨种或同门换种取得已发现的豆种或麻种，准备一块空田。课程报价明确标出自动选定的田块与作物（优先可用豆种，其次麻种）；执行现有 branchlearn:A4 行动时，按课程报价扣时间精力、实际扣1份种子并播种，掌握 A4，作物之后正常季末生长与收获。没有种子或空田不能提交；不重复扣教学样品。同门传授仍可直接学会 A4，之后种植仍需发现与持有对应种子。已掌握者不能重复通过学习播种。

O3/O4/O5 仍沿用原有阶段回报加成，不叠乘；界面单独收在「阶段结算核算」，不伪称为市场或资本能力。营销、定价、融资、投资与清障工具升级尚未新增机制。学堂未来阶段只显示概览，当前阶段节点按用途分支显示，详情提供实际效果、使用位置、前置与行动报价。AI 的 branches 分区同步提供阶段、用途、学习方式及完整学习行动报价。

农耕村落、市镇百工、电力工业各最多5代；主动结算按当前产能和弟子年龄估算剩余时间，最后一代交接强制结算仅兑现实际生产。跨时代延续同一批人物、师徒谱系、修为和知识，不重新生成人物。现代开启240季公开期限。

## 季末生活事件

每季在生产、购粮和家庭口粮结算之后、健康老化与交接判定之前，从在世的当代传人中随机选一人，结算一次生活事件。学习、劳动、照顾他人与休养会改变事件类型的权重及顺利概率；缺粮、低健康、疲惫增加波折，开朗或温厚的性格及已有关系也会影响结果。换人不转移本季行动记录，不投入相关行动也可能获得机遇或遭遇波折。原有修道季度启发独立保留。

事件池共有25组、50种正负结果。先按原有权重选类别，再从符合人物处境的事件组中抽取；有其他合格事件组时避开本人上一次的同组事件，只有一组符合时允许重复。相关投入按所抽事件判断，例如授业问答受教导投入影响，集市对账受交易投入影响。以下条件只决定事件组是否开放，不保证出现或得到正面结果。

师徒页可与在世门人谈心，每对人物每季一次，基础消耗2时间、1精力，双方关系提高1。关系范围-5至5，关系事件改变1点（重大事件2点），并写入双方记忆与心境；本季谈心对象优先成为关系事件的对方。正负经历的净积累达到4次会改变性格：顺利经历倾向坦率热忱，关系和解倾向温厚耐心，波折倾向谨慎认真；变化后重新累计。

顺利事件且本季有相关投入时，有5%机会获得与经历对应的终身天赋，与出生天赋并存，同类不重复叠加。天赋使用既有实际行动和恢复效果。个人学习点、后天天赋、性格、关系与记忆随本人跨时代、退休保留，不自动复制给弟子；钱财进入共享资产。事件原因、实际增减与最近经历在人物页及模型观察中可见。状态形状更新后需新开游戏，不迁移旧档。

## 道、术与机缘

桌面入口独立为「修炼」页：上层个人五境（定心、观照、知止、守一、通明），下层永久心法，右侧显示选中节点的真实进度、效果与行动条件。境界名称只用于呈现，不改变既有门槛和数值。点击节点查看详情，静修、授徒、研证仍通过统一行动结算；衍生机缘折叠在底部。「师徒」页保留收徒、谱系、交接与身体休养。

静心修道基础耗4时间、2精力，增加2修为；每8修为一境，最高5境。首次亲自学习新课程增加1修为；有效传授课程或修道增加师父1修为。授徒同时占用弟子2时间、1精力，不能无成本传授。

个人道降低学习、生产、教导、休养与任务等行动的时间和精力，不代替知识、实物或电力。基础效果每境4%，每级永久心法额外每境1%，个人效果封顶35%。算入辅助卡和季度启发后总折扣最多40%；正成本至少0.25，保留两位小数。静修、永久研证及抽卡不受折扣。季末本人耕作、供水与加工使用相同报价口径，员工工资不打折。

改进心法要求个人满境，亲自掌握至少4×下一级心法等级的课程、涵盖至少三类学科，并完成耕作、生产、授术中至少两类实际实践。每步研证耗4时间、2精力、6钱，累计8步永久提升一级，最多4级。后人从零修行，逐境发挥更好心法的效果。

每人首次到达一境衍生3气运，储备上限30。抽卡耗6气运，扣费前计算概率；基础/进阶/稀有为80%/18%/2%，仅由当前气运和本人道的小幅偏置改善。四类辅助分别降低学习、生产、教导、筹备成本，每级1%，每类最多3级。重复卡溢出转有限口粮，不退气运、不增加修为或分数。

季初取本人修为作为本季机遇快照；基础机遇率4%，本道效果每10个百分点增加1个百分点。触发后下季某类行动额外减耗2%。招徒只受师父道的小幅资质偏置，不改变已生成候选的天赋。气运为零、完全不抽卡仍可修炼、收徒和挑战危机。

## 供电与消费

电力工业开放 L5/L6/L7、M4/M5；L7 不再等到现代。知识之外仍需实物、前置产品验证和原料；外购设备不赠送制造规程。新产品和配方在制造页、商城与玩家观察中使用同一目录。

电报只协调新订货，不加速既有订单、维修或培训，不突破运输容量，不预知随机天气或未来行情。铝不是从黏土直接得到；需购买氧化铝原料并实际电解。铝导线进入统一导线库存，代表配方替代，不模拟电阻、电压和线路损耗，也不要求制成的铝导线持续耗电。

季末不自动发电、不开启新的电器服务；余电可入储能，未储存的电跨季耗散。旱季产能可从当前天气及供能页直接看到，不读取未来天气。

## 现代使命与评分

进入现代自动召集，只触发一次。四项必需危机为智能系统失控、生物安全、核升级与战争、生态与气候。每项均有技术与协调两条路线，已开始的一档固定路线；依次挑战兜底、稳局、周全三级。

每档依次建立方案、投入保障、跨季验收。方案检查本人所学；技术路线交付导线、黏土、铁或木材，协调路线支付委托费用；生物与气候还须交付可食余粮并留下本季生活口粮。基础部件/余粮为4×难度，协调费8×难度。高档技术路线增加专门课程和真实用电要求，协调路线要求高级组织课程；周全气候还需调试供水设施，周全智能还需发电机产品验证。具体条件随行动公开显示。

各副本只计已完成最高难度：10 / 40 / 90分；高档替换低档成绩，不叠加，最高总分360。未完成的步骤不计分；投入只保留为该档进度，不退款、不抵扣下一档。财富、气运、修为、卡牌和阶段回报不直接给分。

主动结束、240季耗尽或传承中断时结算。四项均至少兜底才算使命完成，否则使命失败并保留已得分数。提前完成兜底可继续冲击高档或主动结束。旧六项家业任务不再开放或另行计分。

现代阶段的生产凭证兑现仍独立保留：本季实际点灯、电报或电解才按100%兑现，否则按85%折算；该项只影响钱，不影响副本成绩。

## 存档与范围

规则仍为0.27.0。存档保存两人预算、师徒关系、个人修为、永久心法、已领境界奖励、候选、卡牌、任务进度及所选发展框架。缺少新结构或框架字段的旧档拒绝加载，不迁移、不覆盖原文件。网页与AI通过统一行动接口使用这些规则，观察不暴露随机状态、寿命或未来天气。

远征同行、联网排行榜及私人婚育系统未实现。本轮不运行tests中的测试，不保存试玩报告；完整长期平衡仍需后续专项验收。

## 地块农场与同门（PixiJS 首版）

地图只表现田块、未知边界、探索地貌和一座简化的自家农舍。仓库、买卖与补给、同门、休息和探索见闻在农场面板操作，不绘制对应建筑或人物。选择稳定地块 ID 后，通过统一行动探索、开垦、播种、灌溉、施肥或收获。季末每块田独立生长，换代保留地块和已发现种子。

- 起始田为 `p2q2`，仍由原有 `economy.field` 结算；新增田各存独立田况。作物生长期、收成、灾害、肥力和留种沿用原规则。自动供水、井泵、持续耕作与既有供粮预测只覆盖起始田；新田手动灌溉扣公共水，新增田收成在实际收获后进入库存。
- 地图从非负坐标向外不断延展；探索相邻未知格需基础2时间/2精力，执行时等概率抽取下表九类事件，产生新的未知边界。未知格不预先包含事件、种子或未来天气。障碍不能开垦，但仍可探索其周边。
- 开垦一格需基础3时间/2精力/4钱。小麦开局可种；豆麻需要已发现种子及A4知识，发现后集市允许补购。所有田共用自家有限种子、工具和劳动预算，设备使用仍扣耐用。
- 与同门聊天双方耗基础1时间，每季一次，关系+1、上限5。以2小麦换2豆种或麻种，每季一次，双方真实扣库存；同门初始各6份种子，靠独立田地收获补充。
- 关系至少1可向掌握A4的同门请教，双方耗基础2时间/1精力。求助灌溉耗本人基础1时间，每季一次；不熟或同门忙碌会拒绝。接受后同门耗2时间/2精力，指定田块补2水。个人修道折扣沿用原报价。
- 地图只读取公开观察，点击提交现有 transition 行动；PixiJS 7.4.3 从本地依赖加载。AI 精简观察含相同地块 ID、可见田况、已发现种子、同门与真实行动报价，不读取私有库存或未来随机状态。
- 保持规则版本0.27.0；缺少探索结构版本2、异穗种子或新增规则字段的旧存档拒绝加载，不迁移、不覆盖。

异穗麦是独立留种的小麦品种，需A0与空田，播种消耗1份异穗种子，不扣普通麦种；成熟收成增加1份，仍受旱涝等原规则影响。收获产物进入普通小麦库存，只返还1份异穗种子，不额外生成普通麦种。市场不出售异穗种子；持续耕作收获后仍按所选普通作物补种。

## 农舍烹饪与农场事务

仅田地与探索页创建 PixiJS 地图；切到农舍、仓库、买卖、同门或见闻时销毁地图与监听，改为独立卡片面板。仓库按口粮收成、留种材料分类，可查看物资详情；买卖沿用真实购物车和交付行动。

农舍灶台开局可用，无设备与后期科技门槛。麦粥：2小麦＋1木材 → 3即食口粮，基础2时间/1精力；炖豆：2大豆＋1木材 → 3即食口粮，基础2时间/1精力；麦豆饭：1小麦＋1大豆＋1木材 → 4即食口粮，基础3时间/1精力。个人减耗沿用统一报价；缺食材、燃料或劳动时不可执行。

烹饪通过 transition 当次扣除库存、存入口粮，季末沿用生活消耗与食品保存规则。不消耗种子，不改变作物产量，不把亚麻作为食材，也不额外给予健康或精力奖励。粮食产出共用即食口粮，不另存菜品保质期；换代继承现有库存与口粮。配方数值位于 catalogs.json 的 cooking 字段。缺少该目录的旧档拒绝加载，不迁移或覆盖。

另一位人物是同门师兄或师姐（按人物性别显示称谓），独立耕作、持有库存和劳动预算，不可切换控制；交谈、换种、请教与灌溉求助的成本和条件沿用现行规则。关系称谓表达同门身份，不新增血缘或婚恋关系。

农舍仅作远景装饰，不属于地块、不可在地图选中，也不随地块缩放拖动。原坐标 p2q4 在新局为普通可耕荒地，开垦仍需支付正常成本；农舍烹饪、休息等从农舍页签进入。旧存档若含 home 地块则拒绝加载，不迁移或覆盖。

### 农场采购与用途说明

手动购买、整单结账及季末自动补粮均不消耗时间或精力，也不预留赶集劳动。仍支付实际价款，受库存、资金、采购预算、服务额度和运输容量限制；现货及订货交付规则不变。购买所得物资沿用既有库存与传承规则。

农场商品与仓库卡片直接展示物资用途及需要先学习的条件，取消通用「行动详情」折叠段和零时间、零精力标签；不可执行原因仍直接显示。
