# 0.27.0 师徒传承、道术修行与现代使命

现行规则以修道习术为成长主线，以现代存续危机为唯一计分来源。门派奉行兼爱、非攻，隐世积累，只有人类存续受到威胁时整体出手。

## 师徒与时代

每位开局传人及寻访候选独立随机生成性别、姓名、肖像样式、行事风格、天赋、职业出身、时代身世、情感牵挂与心愿。姓名不按血缘统一姓氏；所有性别均可获得任一天赋和职业。职业是社会身份，未成年显示职业见习，不赠送课程、设备或额外职业加成；角色能力仍取决于实际天赋、道与术。行事风格以人物文案呈现，肖像沿用现有分性别、分年龄素材。

招募时可查看完整人物资料，生成后保存，不因观察、读档或正式收徒重抽。入门、成年、首次学习新术、初次破境、收徒授业、心法改进、中年、退休与年长等真实经历逐项写入生平，并改变当前心绪；同一里程碑只记录一次。各人原有身世与牵挂保持连续，时代变化只更新当前职业与适应经历，不改写出生背景。成长记录与人物身份跨代保存，已故人物留在谱系中。情感叙事不直接改变数值，不新增婚恋或婚育机制。

每代两位传人，各收一名弟子。开局两人20岁，互无血缘继承关系；寻访生成一位16岁候选并保存，正式收徒后占用下一代席位。候选不在生活模拟中老化，正式入门后逐季成长。不得反复寻访重抽，婚育不决定席位。本轮不新增私人婚育模拟。

18岁成年；两位弟子均成年且在世后才能整代交接。入门修为与课程从零开始，可在交接前由师父教导。交接保留弟子实际所学、门派心法、卡牌、气运、资产及规程，不复制师父修为或个人知识。退休师父在世时仍可请教。

两位当代传人分别拥有时间与精力；切换不刷新预算，结束本季统一结算生活和成长。本人运行的机器须暂停或交给员工后才能切换，以免预留劳动转嫁。耗尽时间不会自动推进季度。

农业、集镇、工业各最多5代；主动结算按当前产能和弟子年龄估算剩余时间，最后一代交接强制结算仅兑现实际生产。跨时代延续同一批人物、师徒谱系、修为和知识，不重新生成人物。现代开启240季公开期限。

## 道、术与机缘

桌面入口独立为「修炼」页：上层个人五境（定心、观照、知止、守一、通明），下层永久心法，右侧显示选中节点的真实进度、效果与行动条件。境界名称只用于呈现，不改变既有门槛和数值。点击节点查看详情，静修、授徒、研证和切换行动者仍通过统一行动结算；衍生机缘折叠在底部。「师徒」页保留收徒、谱系、交接与身体休养。

静心修道基础耗4时间、2精力，增加2修为；每8修为一境，最高5境。首次亲自学习新课程增加1修为；有效传授课程或修道增加师父1修为。授徒同时占用弟子2时间、1精力，不能无成本传授。

个人道降低学习、生产、教导、休养、采购与任务等行动的时间和精力，不代替知识、实物或电力。基础效果每境4%，每级永久心法额外每境1%，个人效果封顶35%。算入辅助卡和季度启发后总折扣最多40%；正成本至少0.25，保留两位小数。静修、永久研证及抽卡不受折扣。季末本人耕作、供水、加工与赶集使用相同报价口径，员工工资不打折。

改进心法要求个人满境，亲自掌握至少4×下一级心法等级的课程、涵盖至少三类学科，并完成耕作、生产、授术中至少两类实际实践。每步研证耗4时间、2精力、6钱，累计8步永久提升一级，最多4级。后人从零修行，逐境发挥更好心法的效果。

每人首次到达一境衍生3气运，储备上限30。抽卡耗6气运，扣费前计算概率；基础/进阶/稀有为80%/18%/2%，仅由当前气运和本人道的小幅偏置改善。四类辅助分别降低学习、生产、教导、筹备成本，每级1%，每类最多3级。重复卡溢出转有限口粮，不退气运、不增加修为或分数。

季初取两位传人的道作为本季机遇快照；基础机遇率4%，平均道效果每10个百分点增加1个百分点。触发后下季某类行动额外减耗2%。招徒只受师父道的小幅资质偏置，不改变已生成候选的天赋。气运为零、完全不抽卡仍可修炼、收徒和挑战危机。

## 供电与消费

工业社会开放 L5/L6、M4/M5，现代开放 L7。知识之外仍需实物、前置产品验证和原料；外购设备不赠送制造规程。新产品和配方在制造页、商城与玩家观察中使用同一目录。

| 设备 / 工序 | 实际投入与结果 |
| --- | --- |
| E01 水电 | 启用后手动调度，每季最多一次，消耗1公共水、1耐用；旱季3电，其余季6电 |
| E02 燃料发电 | 每季最多一次，消耗1精炼燃料、1耐用，产生6电；不耗公共水 |
| E04 储能柜 | 启用后季末储存最多6份余电，每次充电扣1耐用；手动调度时每季最多放电一次 |
| 电灯 | 启用后供能，首次点亮耗1电、1耐用，当代两人当季各增加2可用时间；仍扣学习或劳动精力 |
| 电报终端 | 启用后供能，每季耗1电、1耐用；此后当季新订货即时交付，仍扣价款、库存、运输 |
| 电解槽 | 无启停开关，按批加工；2氧化铝原料＋3电＋1耐用 → 2铝 |
| 铝导线工艺 | 1铝＋1绝缘聚合物 → 2份绝缘导线，进入已有线圈、电缆等配方 |
| F07 化工设备 | 制造后支持原有精炼燃料和电池工序，补齐燃料发电、储能柜的自制路径 |

操作顺序：安装设备 → 启用需要的发电机、储能、照明或电报 → 执行本季供能 → 按需加工或向副本供电。调度基础耗2时间、1精力，实际报价受本人道的效果影响，先水电、后燃料、再储能放电，负载按照明、电报顺序结算。可先停用非必要负载，把电留给加工与工程。缺料、缺水、设备维修或缺电均停机，不凭空产生能力。

电灯把基础12时间的当季预算提高到14，但调度本身仍花时间；与同时安排的其他用电任务共同衡量收益。关闭再开启不会刷新当季额度。所谓夜间学习使用这2份额外时间，不存在无限透支或零精力学习。

电报只协调新订货，不加速既有订单、维修或培训，不突破运输容量，不预知随机天气或未来行情。铝不是从黏土直接得到；需购买氧化铝原料并实际电解。铝导线进入统一导线库存，代表配方替代，不模拟电阻、电压和线路损耗，也不要求制成的铝导线持续耗电。

季末不自动发电、不开启新的电器服务；余电可入储能，未储存的电跨季耗散。旱季产能可从当前天气及供能页直接看到，不读取未来天气。

## 现代使命与评分

进入现代自动召集，只触发一次。四项必需危机为智能系统失控、生物安全、核升级与战争、生态与气候。每项均有技术与协调两条路线，已开始的一档固定路线；依次挑战兜底、稳局、周全三级。

每档依次建立方案、投入保障、跨季验收。方案检查本人所学；技术路线交付导线、黏土、铁或木材，协调路线支付委托费用；生物与气候还须交付可食余粮并留下本季生活口粮。基础部件/余粮为4×难度，协调费8×难度。高档技术路线增加专门课程和真实用电要求，协调路线要求高级组织课程；周全气候还需调试供水设施，周全智能还需发电机产品验证。具体条件随行动公开显示。

各副本只计已完成最高难度：10 / 40 / 90分；高档替换低档成绩，不叠加，最高总分360。未完成的步骤不计分；投入只保留为该档进度，不退款、不抵扣下一档。财富、气运、修为、卡牌和阶段回报不直接给分。

主动结束、240季耗尽或传承中断时结算。四项均至少兜底才算使命完成，否则使命失败并保留已得分数。提前完成兜底可继续冲击高档或主动结束。旧六项家业任务不再开放或另行计分。

现代阶段的生产凭证兑现仍独立保留：本季实际点灯、电报或电解才按100%兑现，否则按85%折算；该项只影响钱，不影响副本成绩。

## 存档与范围

规则仍为0.27.0。存档保存两人预算、师徒关系、个人修为、永久心法、已领境界奖励、候选、卡牌及任务进度。缺少新结构的旧档拒绝加载，不迁移、不覆盖原文件。网页与AI通过统一行动接口使用这些规则，观察不暴露随机状态、寿命或未来天气。

远征同行、联网排行榜及私人婚育系统未实现。本轮不运行tests中的测试，不保存试玩报告；完整长期平衡仍需后续专项验收。
