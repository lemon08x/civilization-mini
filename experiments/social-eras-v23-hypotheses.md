# 0.23 建设完成结算与剩余产能推算假设

用户授权：建设是主要过程；阶段保留总时间预算；完成后按已建系统产能、人员和资源约束推算剩余净收益，加上建设期间实际生产；收益归属当前阶段，后期自来水不追溯取消前期水井。

- H1：四阶段建设目标为水井 / 机械供水 / 轴加工 / 家业试炼。建成并调试（现代为副本完成）后，当季实际生产入账即可结算进入下一社会。
- H2：剩余季数 = 时间预算 − 已过季数。建设越快，推算窗口越长。未完成目标则到期只兑实际生产，不发剩余推算。
- H3：推算不掷未来天气。已调试且未暂停的供水系统，田间按保障灌溉连续收获；主动暂停则按场景干旱比例折减。刚建成尚未安排人员的，剩余时间按本人可承担劳动计算。轴加工同样按未暂停的工位推算每季一批。
- H4：凭证仍按阶段权重与社会卡/管理课修正；推算与实际生产进入同一账户，本阶段兑现后清零。农业阶段的井收益在集镇出现机械供水或现代出现自来水后保持不变。

验证：专项单测、12季短窗口固定种子建井时机对照（脚本基线，不是大模型试玩）、短时界面核验。不运行完整768季。
