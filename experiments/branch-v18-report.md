# 0.18.0 分支路线实施检查

问题：三条浅分支是否可以从正常开局到达实际农业、工匠交付及本地用电？

方法：共10个有限脚本基线，无大模型调用。均为river场景、种子17，策略只读取observeSession并通过submitCommand行动；不修改状态。失败后只修正生活策略，没有改游戏数值。不同策略不能作为控制变量一致的新旧版对照。原档全部保留并通过当时实现的严格重放。

农业、电工脚本为保障生活额外选择O0；电工也保留初始A0。故观察中的已知节点总数可能超过目标必需集合，不应将额外生活知识算作隐藏制造前置。结束季包含准备、生活及目标后的观察；不是最优路线或预期通关季数。机械运行仍有本人种田与临时收入，不能据此声称工厂完全自负盈亏。
