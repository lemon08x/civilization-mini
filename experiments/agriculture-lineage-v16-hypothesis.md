# 家学接续与作坊过渡 · 0.16.0 候选

针对 v15 十局对照中的两个结构问题：窑场之后水利把三条工业链捆成一次装运；换代后个人知识清零，后辈要用大量行动把科技树重学一遍。

不覆盖 `rulesets/`。候选见 `experiments/agriculture-civilization.v16.json`。v15 行为保持不变。

## 因果修改

规则候选 0.16.0，标志 `householdLineage`。个人能力仍不整套复制给全世界；家族记录是本家写下的方法。

1. **家学接续。** 换代时把本代已掌握学科写入家族记录，后辈知识取 `max(已教导, 家族记录)`。窑、存货、教材本来就留在家里；现在后辈也能按记录继续加工，不必从第一阶重学。新课题、新设备、超过记录的前沿仍要本人学习或研究。本代生产证明不带到下一代。
2. **作坊过渡。** 在窑场与水利之间增加「传动工场」：力学3、材料2，只投入轴2，证明本代加工过轴。奖励纤维4、油1、绳1、8钱、M03、供应5。水利改为只要组织1和密封件2，用密封证明；不再同时索取轴、密封和绳。组织1可免费学习，随后可签供粮协议。
3. **分批装运。** 不必一次凑齐全套，有什么运什么。
4. **本代证据。** 早期非逐季副本承认本代已经做过的生产证明。先做轴再开传动工场仍然有效。后期逐季副本不变。

输电及以后的知识8与电力层仍未改。本次只把窑场到水利的断崖拆开，并去掉换代复读税。

## 最小验证

- 单测：v15 目录与整套装运不变；v16 换代接续家学、分批装运、本代先加工再开副本、传动工场可达且奖励一次。
- 对照：同一脚本基线、river、种子17。v15 仍应卡在水利；v16 应完成传动工场并进入水利，换代后力学/材料不必从 0 重学。不调用大模型。
