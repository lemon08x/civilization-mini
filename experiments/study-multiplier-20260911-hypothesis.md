# 理论学习倍率敏感性：运行前假设

规则 0.4.0，2026-09-11。研究者为 Grok 4.6（xAI 编程工具，无独立 xAI API 调用）；实际行动由 scripted 脚本基线决定，不是 Grok 玩家测试。

问题：框架 `learning-friction` 指出 `studyMultiplier=1` 已在合法下界，不能再降。现行脚本会执行 `study:*` 与 `teach:*`。仅将 `studyMultiplier` 从 1 改为 2，检查理论投入增加是否改变掌握、实际产品与传承，而不是被实践、原料或生活成本挡住。这是敏感性检查，不是把倍率提高当作更好的设计。

预期机制：`studyRequired = max(1, tech.study × studyMultiplier − 家学减免 − 领悟 − 有利经验)`。木作/陶作基础理论 2，控火/储存 1。无家学时候选约为 4 / 2 次学习；林地陶作购买外来方法后陶作进入家学，理论次数约 1→3。脚本在 `studied < required` 时继续学习，因此会触发。

成功信号（研究识别，不是采纳理由）：至少一条木作或陶作路线的掌握节点、完工产品或继承节点因额外理论行动而变化；配对缺粮不增加。金额、采料、做工、期末在制品只作解释，不能单独证明应提高倍率。

反证及停止：所有配对只增加学习/教导次数，掌握、完工、继承与缺粮完全不变，则理论倍率不是当前脚本下的结果瓶颈，停止。任一配对新增缺粮，或基线已掌握/已继承的节点在候选中丢失，视为副作用，停止，不搜索 3 或其他参数。不能把钱财下降或学习变慢自动写成应采纳更高倍率。

首批：林地 / 黏土河谷 × potter / mixed × 种子 17 × 基线/候选，共 8 局，每局最多 60 命令。候选独立保存，运行中不改规则或策略。

留出（预先指定，仅当触发）：若首批至少一条路线的掌握数、完工产品或继承节点数发生变化，且没有新增缺粮、也没有丢失基线已有的掌握/继承，则用未参与调参的种子 29，仅复核黏土河谷 potter / mixed，共 4 局。总计最多 12 局。没有改善或出现明显副作用则不跑留出。

限制：当前 potter/mixed 不建陶窑、工作台或委托，不覆盖设施回收与广义跨代经营。20 个规划节点不能模拟。不能用未尝试的行动推断参数失效。本轮不自动采纳；至多形成暂不采纳或待决策提案，`adoptedVersion` 为 null。
